## 3. MCP 接口清单（直播间业绩列表 + 排班业绩控制器）

### 3.1 直播间业绩列表

- `POST /governance/performance/live-room/pageLiveRoomPerformance`
- 作用：按直播间维度查询业绩列表（返回直播间基础信息 + 周期统计 performanceStatistics）
- 主要使用场景：直播间业绩列表页卡片数据源；详情页/历史页用于按 anchorNumber 查询当前直播间的周期统计

请求参数（核心）：

- `page/limit`
- `platform`（0抖音/1快手/2视频号）
- `companyId/deptId/teamId`
- `anchorName`（主播名模糊）

### 3.2 排班业绩（按天统计）

- `POST /governance/performance/live-room/dailyStats`
- 作用：以天为维度统计排班业绩（分页）

请求参数（核心）：

- `page/limit`
- `startTime/endTime`（时间范围）
- `anchorName`（模糊）
- `liveRoomId`（可选；页面选中直播间时传入）
- `sortField/sortOrder`（当前固定：`statsDate/DESC`）

### 3.3 排班业绩（班次明细分页）

- `POST /governance/performance/live-room/pageQuerySchedule`
- 作用：按排班（班次）维度统计业绩（分页）

请求参数（核心）：

- `page/limit`
- `startTime/endTime`
- `anchorName`
- `liveRoomId`（可选；页面选中直播间时传入）

### 3.4 班次业绩详情

- `GET /governance/performance/live-room/schedulePerformance/{id}`
- 作用：编辑时拉取详情（人员列表、业绩数据 performanceData、字段 modified 状态、图片 URL 等）

### 3.5 班次业绩保存/修改

- `POST /governance/performance/live-room/schedulePerformanceSave`
- 作用：录入/编辑班次业绩

当前实现：

- `id` 有值：编辑
- `id` 为空：新增
- `scheduleId` 未接入（页面按“手动录入时间段”保存）
- `performanceData` 仅提交 `{ value }`，未接入凭证图片上传（imageUrl）

### 3.6 班次业绩删除

- `POST /governance/performance/live-room/deleteSchedulePerformance`
- 入参：`{ id }`

## 4. 字段映射说明

### 4.1 直播间列表卡片（pageLiveRoomPerformance）

后端字段 -> 卡片展示字段：

- 直播间信息：
  - `anchorName` -> 主标题
  - `anchorAvatar` -> 头像
  - `companyName/deptName/teamName` -> 所属组织
  - `managerUserInfos[]` -> 管理者列表
- 周期业绩统计：
  - `performanceStatistics.sessionStats` -> 场次（count + duration 分钟，前端格式化）
  - `performanceStatistics.viewCount` -> 场观
  - `performanceStatistics.salesRevenue` -> 销售
  - `performanceStatistics.refund` -> 退款
  - `performanceStatistics.netSales` -> 净销售
  - `performanceStatistics.investment` -> 投放

### 4.2 按天统计表（dailyStats）

后端字段 -> 表格字段（页面内部映射）：

- `statsDate` -> `date`
- `scheduleCount` -> `sessionCount`
- `liveDurationMinutes` -> `duration`（格式化为“X小时Y分”）
- `staffList[] (StaffDailyStats)` -> `staffList[]`（用于人员列展示）
- `viewCount` -> `views`
- `salesRevenue` -> `sales`
- `refund` -> `refund`
- `netSales` -> `netSales`
- `investment` -> `adCost`
- `roi` -> `roi`

### 4.3 班次明细表（pageQuerySchedule）

后端字段 -> 表格字段（页面内部映射）：

- `startTime/endTime` -> 时间段 + 时长
- `staffList[] (StaffInfo)` -> 人员列（岗位/姓名）
- `viewCount/salesRevenue/refund/netSales/investment/roi` -> 指标列
- `source`（1系统/2手动）-> `数据来源`（系统/手动）

## 5. 交互流程

1. 列表页：
   - 查询/重置筛选后刷新卡片列表与分页
   - 点击卡片进入详情页
   - 点击“查看历史业绩”进入历史页
2. 详情页：
   - 默认展示“直播间业绩”Tab（概览卡片 + 趋势图 + 按天统计表）
   - 按天统计表可点“查看场次明细”，自动切换到“直播场次”并带入当天日期筛选
   - “直播场次”Tab 支持录入/编辑/删除班次业绩
3. 历史页：
   - 展示“直播间业绩 / 直播场次”两类明细，支持按主播与日期范围筛选
   - “直播场次”Tab 支持录入/编辑/删除班次业绩
