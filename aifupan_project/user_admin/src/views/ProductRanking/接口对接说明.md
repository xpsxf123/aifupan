对应接口（MCP「商品业绩控制器」）：

1. 商品排行分页查询：`POST /governance/performance/product/ranking`
2. 商品关联直播场次分页查询：`POST /governance/performance/product/sessions`
3. 商品关联分公司列表查询：`POST /governance/performance/product/companies`

## 3. 页面请求参数映射

### 3.1 时间范围（必传）

- 页面使用 `DateQuickPicker` 维护 `dateRange: [startDate, endDate]`，格式为 `YYYY-MM-DD`
- 三个接口均使用相同的 `startDate/endDate`

默认值：

- `startDate = 今天-7天`
- `endDate = 昨天`

### 3.2 分页参数

- 商品排行：Curd 传入 `page/pageSize`，映射为接口 `page/limit`
- 关联直播：弹窗分页使用 `page/pageSize`，映射为接口 `page/limit`
- 来源组织：接口返回列表（无分页参数）

### 3.3 排序参数

当前实现（可后续按 UI 增加交互）：

- 商品排行：`sortBy = salesAmount`，`sortOrder = desc`
- 关联直播：`sortBy = startTime`，`sortOrder = desc`
- 来源组织：`sortBy = salesAmount`，`sortOrder = desc`

## 4. 字段展示映射

### 4.1 商品排行表格

接口：`/governance/performance/product/ranking`

| UI 字段            | 接口字段                      |
| ------------------ | ----------------------------- |
| 商品名称           | `productName`                 |
| 销量               | `quantity`                    |
| 销售额             | `salesAmount`（元）           |
| 曝光点击率         | `exposureClickRate`（%）      |
| 点击付款率         | `clickPaymentRate`（%）       |
| 曝光成交率         | `exposureConversionRate`（%） |
| 千次成交           | `gpm`                         |
| 关联直播（可点击） | `sessionCount`                |
| 来源组织（可点击） | `companyCount`                |

说明：

- 「排行」列为前端根据分页计算的 `rank`，用于展示 Top1/2/3 图标与序号。

### 4.2 关联直播弹窗表格

接口：`/governance/performance/product/sessions`

| UI 字段                 | 接口字段                     |
| ----------------------- | ---------------------------- |
| 主播头像                | `anchorAvatar`               |
| 主播名称                | `anchorName`                 |
| 开播时间                | `startTime`                  |
| 场次时长                | `duration`（秒，前端格式化） |
| 销量                    | `quantity`                   |
| 销售额                  | `salesAmount`（元）          |
| 场观（原 UI“人气峰值”） | `viewCount`                  |

### 4.3 来源组织弹窗表格

接口：`/governance/performance/product/companies`

| UI 字段  | 接口字段            |
| -------- | ------------------- |
| 来源组织 | `companyName`       |
| 销量     | `quantity`          |
| 销售额   | `salesAmount`（元） |
| 场观     | `viewCount`         |

## 5. 交互说明

- 商品排行表格中：
  - 点击「关联直播」数值，打开关联直播弹窗并带入当前行 `productId/productName/sessionCount`
  - 点击「来源组织」数值，打开来源组织弹窗并带入当前行 `productId/productName/companyCount`
  - 当数量为 0 时，链接为禁用态，不触发弹窗
