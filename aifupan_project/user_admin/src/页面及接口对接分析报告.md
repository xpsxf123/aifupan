## 一、 列表页跳转详情页逻辑排查

经过全量代码扫描，针对类似“点击列表进入详情页时 ID 取值错误 / 参数名错误”的问题进行了排查。除已修复的个人业绩（`employId` 字段名不匹配）外，以下为其他核心列表页的跳转检查结果：

| 模块列表页 | 跳转目标页 | 参数传递方式 | 后端接收校验 | 状态 |
| --- | --- | --- | --- | --- |
| **直播间业绩列表** (`LiveRoomPerformance/List`) | 直播间业绩详情 / 历史 | 路由路径 `:liveRoomId` | 对应接口使用 `liveRoomId` 正确 | 正常 ✅ |
| **各小组业绩** (`TeamPerformance/TeamData`) | 小组业绩详情 (`TeamDetail`) | 命名路由 `params: { id }` | 对应详情页获取 `route.params.id` 正确 | 正常 ✅ |
| **各部门业绩** (`DepartmentPerformance/BranchData`) | 部门业绩详情 (`DepartmentDetail`) | 命名路由 `params: { id }` | 对应详情页获取 `route.params.id` 正确 | 正常 ✅ |
| **各分公司业绩** (`BranchPerformance/BranchData`) | 分公司业绩详情 (`BranchDetail`) | 命名路由 `params: { id }` | 对应详情页获取 `route.params.id` 正确 | 正常 ✅ |
| **各直播间业绩** (`LiveRoomPerformance/index`) | 直播间概览详情 (`Detail/index`) | 命名路由 `params: { id }` | 对应详情页获取 `route.params.id` 正确 | 正常 ✅ |
| **直播间排班** (`LiveRoomRanking/index`) | 排班详情 (`Detail`) | 命名路由 `query: { id, name }` | 详情页接收 `route.query.id` 正确 | 正常 ✅ |
| **人员排班** (`StaffSchedule/index`) | 人员排班详情 (`Detail/index`) | 命名路由 `query: { liveRoomId, startDate, endDate }` | 详情页接收 `route.query` 数据正确 | 正常 ✅ |

**结论**：其他列表页跳转逻辑均正确，未发现类似的 ID 参数名传递错误。
