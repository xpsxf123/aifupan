# Alert Box

## Description

A static component used to display a warning message for branch company administrators. **Note**: This component currently has hardcoded content and does not accept props. It is specific to the "Branch Company Administrator" scenario.

## Usage

```vue
<template>
  <AlertBox />
</template>

<script setup>
  import AlertBox from '@/components/AlertBox/index.vue'
</script>
```
