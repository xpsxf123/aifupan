# Schema Form Generator

This skill assists in using the `SchemaForm` component to build complex forms.

## Capabilities

- **State Management**: Handle `view`, `add`, `edit`, and custom states.
- **Field Logic**: Configure visibility, readonly, and disabled status per state.
- **Layout**: Grid layout (span) and Grouping (sections).
- **Slots**: Dynamic slot names based on state (e.g., `add-username`, `view-username`).

## Usage

Refer to `references/usage-guide.md` for JSON schema examples and component API.
