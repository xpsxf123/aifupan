# 编码规范与内容追踪

本技能用于强制执行特定的编码规范，并确保所有生成的内容都有记录。

## 1. JavaScript 文档

- **语言**：所有注释必须使用**中文**。
- **函数头**：每个函数必须包含 JSDoc 风格的块注释，描述以下内容：
  - 函数用途（描述）
  - 参数 (@param)
  - 返回值 (@returns)
  - 示例（可选，但推荐）

## 2. CSS/SCSS 开发

- **预处理器**：所有样式**必须**使用 **SCSS**。
- **禁止纯 CSS**：除非外部库有严格要求，否则避免使用 `.css` 文件。

## 3. CSS 架构

- **模块化**：将可复用的样式提取为公共工具类。
- **继承**：使用 `common.scss` 或 `vars.scss` 管理共享样式（颜色、字体、间距）。
- **专用性**：仅对无法通用的组件特定样式使用专用类。
- **结构**：对样式进行逻辑分组（如：布局、文本、组件）。

## 4. 内容追踪

- **目标文件**：`SKILLS_LOG.md`（位于项目根目录）。
- **操作**：每当生成新内容（文件/功能）时：
  1.  向 `SKILLS_LOG.md` **追加**一条记录。
  2.  **格式**：
      - **日期**：当前日期。
      - **摘要**：所创建内容的简要说明。
      - **目录**：新文件/文件夹的路径。
  3.  **更新/删除**：如果内容被修改或删除，添加相应的日志条目以反映变更。

## 使用示例

当用户要求“创建登录页面”时：

1.  生成 `Login.vue` 和 `login.js`。
2.  确保 `login.js` 包含中文 JSDoc 注释。
3.  确保样式写在 `<style lang="scss">` 中。
4.  更新 `SKILLS_LOG.md`：

    ```markdown
    ## [Date] 登录功能

    - **Summary**: 创建了登录表单和认证逻辑。
    - **Directory**: src/views/Login
    ```
