项目默认使用scss写法作为样式文件。项目默认可以使用皮肤配置（满足主题配置，可统一实现样式控制），也可以使用自定义配置。其中皮肤配置的方式使用css3的var方式实现。需要能够控制element-puls的样式，请对element-plus的css变量进行控制，具体可以参考element-plus的文档。项目中如果没有css定义文件，请创建一个css定义文件，并引入到全局。并且css样式文件夹需要包含以下文件：index.scss (全局样式入口文件) vars.scss (全局样式变量) common.scss (全局样式，如全局字体，全局颜色，全局间距，全局填充等...所有可以统一设置的样式都可以写在这个文件中，也可以将部分独立样式缩写之后存放在文件中，能够直接通过class组合式的方式满足需求，需要将flex的各个样式也写在这个文件中) element-plus.scss (element-plus样式控制文件) 需要对element-plus官方的主题样式控制，请将element-plus的主题样式替换代码存放到element-plus.scss文件中，并引入到全局，并且请使用vars.scss文件中的变量进行主题样式控制. 这个文件只是对element-plus最基本的主题样式控制，如颜色，字体大小，间距，填充等...以及表单等组件的基本样式控制。如果要进行样式大改或者组合样式修改需要满足特定的主题请将代码存放到对应的主题文件中，不要将样式存放到element-plus.scss文件中。主题样式文件设置方式(主题样式主要进行格式等布局变化设置，如主题颜色，主题间距，主题填充等...，element-plus的样式大概也需要存放在这里)：theme/default.scss (主题样式) theme/dark.scss (暗黑主题样式) theme/\*.scss (其他主题样式文件)
