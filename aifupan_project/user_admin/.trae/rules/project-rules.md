谨记！！！项目中请不使用ts语法. 项目使用pinia进行状态管理，不适用vuex管理状态。http方法使用/src/http/index.js文件中的http请求封装函数，服务器接口请使用httpBack，客户端接口使用httpClient。如果在复刻代码的时候发现pinia中没有当前状态管理的配置，即刻在pinia中创建对应的状态管理配置。所有vue组件的template代码使用单文件组件的方式进行编写。所有vue组件的style代码使用scoped方式进行编写。所有vue组件的script代码使用setup语法糖进行编写。所有组件的创建发生时，不需要加入额外的不必要内容，除非又特定需求会告知需求在生成特定内容，如果只是生成一个组件，只需要生成架构即可，内容有后续进行添加。所有说明注释，文件说明使用中文。在每个文件头部加入当前文件功能说明。注释方式使用jsdoc注释方式。实现组件功能时，先优先查询hooks文件下的功能是否满足，如果满足则使用hooks功能，如果没有hooks文件则创建文件夹，并且对hooks的功能进行分类。如果hooks功能不能复用，对应的是当前业务的hooks只是为了方便代码的封装而实现的hooks，那么这个hooks则创建在当前组件文件夹下。所有的组件文件都放置在src/components下，组件文件需要文件夹进行分类，文件夹使用组件名称，采用大驼峰的方式，并且在文件内使用index.vue表示为组件主要部分。其他则单独采用驼峰饿方式命名。路由配置文件存放在/src/config/menu.js中,路由配置,导航配置等都使用当前的配置进行配置。各个组件说明文档地址，更具需求使用组件时，查询文档说明生成对应的代码。请在创建或修改对应的router使用方式或者参数时，请在对应文件下创建说明文档，用于后续ai使用学习所用。
