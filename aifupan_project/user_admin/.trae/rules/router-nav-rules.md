项目中的router和导航参数配置规范：router和导航的数据统一使用一个json文件进行配置，文件路径为/src/config/menu.js. menu.js文件包含以下功能：router的路由配置参数，以及导航参数配置参数，能够自动实现路由的二级，三级页面，并且通过特定配置实现在导航中那些页面展示在导航栏中，并且可以自动展示导航层级，如1，2，3级导航。其中导航栏遵守树形结构，如果1级或者二级导航未配置展示，则下级导航将不会显示（哪怕配置了对应展示参数也将无效），或通过特定的配置则可以将二级（或二级以下）导航等级提升或直接展示到1级导航（这个功能不常用但是可能存在）。路由参数配置说明文档： /src/router/README.md.
