## 交互规范

### 二次确认

- **组件选择**：在需要进行二次确认的操作中（如删除、停用等），**必须优先使用 `el-popconfirm` (气泡确认框)**。
- **例外情况**：仅在需要复杂的交互或包含表单输入的确认场景下，才使用 `ElMessageBox` 或 `Dialog` 弹窗。
- **实现方式**：在 `TableAction` 或类似组件中，应通过配置项（如 `confirm` 对象）来启用 `el-popconfirm`，而不是在事件处理函数中手动编写确认逻辑。
