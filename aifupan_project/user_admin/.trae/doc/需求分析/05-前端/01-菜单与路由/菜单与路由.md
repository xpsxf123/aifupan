# 前端文档｜菜单与路由

## 1. 菜单树（两级）

- 我的排班和业绩
  - 个人排班
  - 个人业绩
  - 个人信息
- 业绩汇总
  - 公司业绩罗盘
  - 直播间列表（业绩）
  - 按不同组织查看
- 商品排行榜
- 直播间排班
- 直播间业绩
- 人员业绩和排班
  - 人员业绩
  - 人员排班（需求中未完整展开，预留）
- 部门和人员
  - 人员（Tab）
  - 直播间（Tab）
  - 小组和部门（Tab）
  - 子公司（Tab）
  - 岗位（Tab）

## 2. 推荐路由规划（示例）

```json
{
  "routes": [
    { "path": "/my/schedule", "name": "MySchedule", "menu": "我的排班和业绩/个人排班" },
    { "path": "/my/performance", "name": "MyPerformance", "menu": "我的排班和业绩/个人业绩" },
    { "path": "/my/profile", "name": "MyProfile", "menu": "我的排班和业绩/个人信息" },

    { "path": "/summary/company-compass", "name": "CompanyCompass", "menu": "业绩汇总/公司业绩罗盘" },
    { "path": "/summary/live-rooms", "name": "SummaryLiveRooms", "menu": "业绩汇总/直播间列表（业绩）" },
    { "path": "/summary/by-org", "name": "SummaryByOrg", "menu": "业绩汇总/按不同组织查看" },

    { "path": "/products/rank", "name": "ProductRank", "menu": "商品排行榜" },

    { "path": "/schedule/live-rooms", "name": "LiveRoomScheduleList", "menu": "直播间排班" },
    { "path": "/schedule/live-rooms/:liveRoomId/config", "name": "LiveRoomScheduleConfig", "menu": "直播间排班" },
    { "path": "/schedule/live-rooms/:liveRoomId", "name": "LiveRoomScheduleDetail", "menu": "直播间排班" },

    { "path": "/performance/live-rooms", "name": "LiveRoomPerformanceList", "menu": "直播间业绩" },
    { "path": "/performance/live-rooms/:liveRoomId", "name": "LiveRoomPerformanceDetail", "menu": "直播间业绩" },
    { "path": "/performance/live-rooms/:liveRoomId/sessions", "name": "LiveRoomSessionDetail", "menu": "直播间业绩" },

    { "path": "/staff/performance", "name": "StaffPerformanceList", "menu": "人员业绩和排班/人员业绩" },
    { "path": "/staff/performance/:employeeId", "name": "StaffPerformanceDetail", "menu": "人员业绩和排班/人员业绩" },

    { "path": "/org/manage", "name": "OrgManage", "menu": "部门和人员" }
  ]
}
```

## 3. Tab 容器路由建议

- /org/manage?tab=employees|liveRooms|orgUnits|subsidiaries|positions
- Tab 内路由可选用 query 方式保持 URL 可分享
