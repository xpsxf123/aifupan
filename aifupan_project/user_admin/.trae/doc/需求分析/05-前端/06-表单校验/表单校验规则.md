# 前端文档｜表单校验规则

## 1. 人员（添加/编辑）

- 姓名：必填，1-50 字
- 头像：必填（若产品要求）
- 手机号：必填，11 位大陆手机号；短信验证码必填且需通过校验
- 邮箱：选填；格式校验
- 岗位：必选（来自岗位列表）
- 类型：必选（全职/兼职）
- 组织归属：可为空；若选择子公司则部门列表仅显示该子公司范围
- 管理权限：
  - 选部门/小组/直播间管理者时：必须选择至少 1 个负责范围
- 录制权限：
  - 开启时：检查可绑定子账号数量>0；否则阻止并提示扩容
- 人数上限：提交前二次校验（并发达到上限需后端返回错误并刷新）

## 2. 直播间（新建/编辑）

- 平台：必选
- 账号 ID：必填；创建时校验唯一；不存在时提示原因
- 行业：三级级联，必选（若产品要求）
- 首播日期：选填
- 归属组织：子公司/部门/小组均可为空（但用于业绩归属，建议至少部门）
- 管理者：至少 1 个（若产品要求）

## 3. 组织（部门/小组/子公司）

- 名称：必填，1-50 字；同层级不重复（建议）
- 排序：数字，>=1
- 备注：0-500 字
- 管理者：可多选；需满足“只能从更高层级管理者中选”的规则
- 版本限制：子公司创建需检查套餐

## 4. 直播间首次排班配置

- 开始/结束时间：
  - HH:mm 格式或“不限”
  - 开始<结束（不为“不限”时）
- 班次时长：至少 1 个；分钟>0
- 时间轴单位：120/60/30/15 之一
- 休息时长：选择休息时必填且>0
- 岗位配置：至少 1 个

## 5. 排班新增/编辑

- 时间段：必填；start<end；跨天按产品规则处理
- 重复：可多选周一-周日
- 排班结束日期：必填；<=30 天
- 类型：主播/助播/场控（固定）
- 人员：必选
- 冲突校验：人员冲突/房间冲突/并发冲突均需提示

## 6. 场次数据录入/编辑

- 人员：必选（成员+角色）
- 场观/销售/退款/投放/投放产出：数字>=0
- 净销售：自动计算，不可手填
- ROI：自动计算；投放=0 时 ROI 展示规则明确
- 截图：按直播间类型要求 1 或 2 张；未配置类型默认 2 张
- 提交二次确认：确认业绩归属人员勾选状态
