# 前端文档｜状态共享与持久化策略

## 1. 跨页面共享状态（建议）

- 当前用户（me）：tenantId、role、dataScope、默认菜单、导出权限、版本限制（人数/子公司/子账号）。
- 当前组织筛选（orgFilter）：subsidiaryOrgId、departmentOrgId、groupOrgId。
- 当前时间范围（dateRange/datePreset）：今日/昨日/本周/本月/自定义 start-end。
- 当前平台筛选（platformFilter）：抖音/快手/视频号等。

## 2. 共享范围建议

- 全局（跨所有页面）：
  - me、版本限制、导出权限、默认组织（若有）
- 模块级（业绩模块）：
  - metric 选中项、datePreset、orgFilter
- 模块级（排班模块）：
  - datePreset、timeGridMinutes（若与配置联动）、最近访问直播间

## 3. 持久化策略（建议）

- localStorage：
  - 最近使用的筛选条件（按路由 key 分开存）
  - 最近一次 datePreset
- sessionStorage：
  - 页面间跳转携带的临时参数（例如从列表跳转详情的定位信息）

## 4. 缓存策略（建议）

- me：启动时拉取并缓存，角色切换后强制刷新
- 字典类（岗位/角色/组织树）：按 tenantId 缓存，变更后失效刷新
- 列表类（人员/直播间/排行）：不做强缓存，支持分页与查询
