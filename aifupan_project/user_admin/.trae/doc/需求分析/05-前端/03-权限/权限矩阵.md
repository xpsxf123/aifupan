# 前端文档｜权限矩阵（页面/操作）

## 1. 角色定义（系统默认）

- owner：主账号
- superAdmin：超级管理者（仅爱复盘子账号可成为）
- subsidiaryAdmin：子公司管理者
- departmentAdmin：部门管理者
- groupAdmin：小组管理者
- liveRoomAdmin：直播间管理者
- employee：普通员工
- custom：自定义角色（菜单权限可配置）
