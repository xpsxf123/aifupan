# 前端文档｜接口清单（建议版）

本清单为前端对接所需的接口边界与字段建议，便于前后端对齐；最终以后端实际接口为准。

## 1. 认证与会话

- GET /api/me
- POST /api/auth/login
- POST /api/auth/switch-account

## 2. 组织与人员

- GET /api/org-units?orgType=&parentOrgId=&keyword=
- POST /api/org-units
- PUT /api/org-units/{orgId}
- DELETE /api/org-units/{orgId}

- GET /api/positions
- POST /api/positions
- PUT /api/positions/{positionId}
- DELETE /api/positions/{positionId}

- GET /api/roles
- POST /api/roles
- PUT /api/roles/{roleId}

- GET /api/employees?orgId=&positionId=&name=&mobile=&page=&pageSize=
- POST /api/employees
- PUT /api/employees/{employeeId}
- DELETE /api/employees/{employeeId}
- POST /api/employees/{employeeId}/reset-password

## 3. 直播间

- GET /api/live-rooms?platform=&orgId=&keyword=&page=&pageSize=
- POST /api/live-rooms
- PUT /api/live-rooms/{liveRoomId}
- DELETE /api/live-rooms/{liveRoomId}

## 4. 排班

- GET /api/schedule/live-rooms/{liveRoomId}/config
- PUT /api/schedule/live-rooms/{liveRoomId}/config

- GET /api/schedule/live-rooms/{liveRoomId}/shifts?startDate=&endDate=
- POST /api/schedule/live-rooms/{liveRoomId}/shifts
- PUT /api/schedule/shifts/{shiftId}
- DELETE /api/schedule/shifts/{shiftId}

- GET /api/schedule/my?startDate=&endDate=

冲突检测（可合并到创建接口返回）：

- POST /api/schedule/shifts/check-conflicts

## 5. 业绩（直播间/人员/公司）

直播间业绩列表：

- GET /api/performance/live-rooms?platform=&departmentOrgId=&groupOrgId=&datePreset=&page=&pageSize=

直播间详情（概览/趋势/明细）：

- GET /api/performance/live-rooms/{liveRoomId}/overview?datePreset=&start=&end=
- GET /api/performance/live-rooms/{liveRoomId}/trend?metric=&start=&end=
- GET /api/performance/live-rooms/{liveRoomId}/daily?start=&end=&page=&pageSize=
- POST /api/performance/live-rooms/{liveRoomId}/export

场次汇总/明细：

- GET /api/performance/live-rooms/{liveRoomId}/sessions/summary?start=&end=
- GET /api/performance/live-rooms/{liveRoomId}/sessions?start=&end=&hostEmployeeId=&page=&pageSize=
- POST /api/performance/live-rooms/{liveRoomId}/sessions
- PUT /api/performance/sessions/{sessionId}
- DELETE /api/performance/sessions/{sessionId}

人员业绩：

- GET /api/performance/employees?orgId=&positionId=&name=&mobile=&datePreset=&page=&pageSize=
- GET /api/performance/employees/{employeeId}/overview?datePreset=&start=&end=
- GET /api/performance/employees/{employeeId}/trend?metric=&start=&end=
- GET /api/performance/employees/{employeeId}/daily?start=&end=&page=&pageSize=
- POST /api/performance/employees/{employeeId}/export

公司业绩罗盘：

- GET /api/performance/company/overview?datePreset=&start=&end
- GET /api/performance/company/trend?metric=&start=&end
- GET /api/performance/company/daily?start=&end&page=&pageSize=
- GET /api/performance/company/subsidiary-share?datePreset=
- GET /api/performance/company/top?metric=&datePreset=
- POST /api/performance/company/export

按组织查看直播间业绩：

- GET /api/performance/by-org?orgId=&datePreset=&page=&pageSize=

## 6. 商品排行榜

- GET /api/product-rank?orgId=&keyword=&datePreset=&start=&end&page=&pageSize=
- GET /api/product-rank/{productId}

## 7. 文件上传（头像/截图）

- POST /api/files/upload
