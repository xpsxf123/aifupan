# BRD｜商品排行榜

## 1. 模块定位

提供公司维度（以及可下钻到子公司/部门范围）商品销售效果排行榜，用于运营与管理决策；数据来自平台汇总（T+1）。

## 2. 角色与数据可见性

- 超级管理员/集团管理员：可查看全量数据。
- 子公司管理员：仅可查看管辖范围内直播间带来的商品数据。
- 部门负责人/部门管理员：仅可查看本部门管辖直播间的商品数据（是否包含小组范围按组织归属定义）。

## 3. 数据来源与时效

- 数据来源：巨量百应直播大屏基础版（抖音等），T+1。
- 商品范围：来自直播间销售商品（平台口径）。

## 4. 筛选与检索

- 商品名称：模糊匹配。
- 时间筛选：开始时间-结束时间；快捷选项（今日/昨日/近 7 日/近 30 日）。

## 5. 指标字段（集团视角为基准）

默认展示 8 项（原文口径）：

- 销售排名（不可隐藏）
- 商品信息：商品图 + 商品名 + 单价 + 店铺名（不可隐藏）
- 销量/退单量
- 销售额/退款额
- 曝光点击率
- 点击付款率
- 曝光成交率
- 千次成交
- 关联直播间
- 关联场次
- 来源组织：子公司-部门-小组（无子公司则展示部门）
- 操作：查看商品（或查看详情）

## 6. 下钻视角

- 子公司视角：展示某子公司范围内商品榜。
- 部门视角：展示某部门范围内商品榜。
- 约束：下钻后的可见数据需满足角色数据范围。
