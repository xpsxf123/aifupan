# BRD｜排班体系（个人排班 + 直播间排班）

## 1. 模块定位

为直播业务提供可视化排班：一套“直播间排班总表”（租户共享）与多视角展示（个人视角/直播间视角），支持新增/编辑/批量、冲突检测与历史查询。

## 2. 角色与权限

- 普通员工：仅可查看个人排班（今日/明日/昨日/本周/下周/本月等）。
- 直播间管理者：查看本直播间排班；是否可编辑按配置（建议可编辑）。
- 主账号/超级管理者/组织管理者：可查看与编辑排班；可创建与调整规则。

## 3. 排班对象与基本口径

- 排班对象：直播间（排班表挂载在直播间维度），人员被分配到排班中。
- 角色类型：主播/助播/场控（固定类型；是否扩展到运营等，在直播间首次排班配置中可配置岗位，但排班展示仍按三类角色为主口径）。
- 时间轴：以 0:00-23:00 为横轴；按自然周为默认视图；支持周/月切换与左右拖动。

## 4. 直播间首次排班配置（关键前置）

用于定义直播间时间轴与分隔规则，影响：

- 班次开始/结束时间与时长默认值
- 时间轴刻度（60/30/15 等）
- 是否休息/休息时长
- 岗位配置（默认：主播/中控/副播，可增减）

录制说明（影响业务解释与用户指引）：

- 日不落直播间（超过 24 小时）：开始/结束时间可选择“不限”。
- 连续开播且班次时长不定：通过“切割班次”分割场次与业绩；不休息时每班次结束停止录制并分段；休息时自动分段但不停止录制，直到下播。

## 5. 排班管理（直播间排班详情）

### 5.1 展示规则

- 默认展示：当前自然周（周一-周日）。
- 支持：切换下周/本月/下月；查看历史排班记录（一年内）。
- 日期状态：已过（灰色）、今日（紫色）、未到（黑色）。
- 排班块状态：
  - 已结束：深色底白字
  - 未排班：浅绿底深绿字
  - 未开始：紫底白字

### 5.2 新增排班

新增入口：点击“未排班区域”。排班信息包含：

- 日期与时间段：支持拖拽或手动调整
- 默认开始时间/结束时间：来自“场次模块”
- 重复：周一到周日多选
- 排班结束日期：必填，最长 30 天
- 类型：主播/助播/场控（不可改）
- 人员：输入检索选择

冲突检测：

- 同一人员在其他直播间同时间段已有排班：提示冲突（提示策略在 FRD 定义为“阻止/允许覆盖/保留”）。
- 同一直播间同时间段已有排班：提示冲突。
- 多用户同时操作：并发冲突提示；批量新增时“冲突日期失败、其他日期成功”。

### 5.3 编辑排班

- 点击排班块打开详情，支持修改排班内容（时间段/人员/重复等）。

## 6. 多视角展示

### 6.1 个人排班（我的排班和业绩-个人排班）

- 个人排班详情与周视图展示。
- 快捷汇总：今日/明日/昨日/本周/下周/本月排班入口。

### 6.2 直播间排班（直播间排班-直播间列表/详情）

- 列表页展示每个直播间的今日/明日/本周/本月排班概览与入口。
