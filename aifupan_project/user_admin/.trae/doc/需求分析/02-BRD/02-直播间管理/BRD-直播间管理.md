# BRD｜直播间管理

## 1. 模块定位

对租户内“自有直播间”进行统一管理与归属维护（组织归属、管理者、监控账号、业绩统计账号），为排班与业绩看板提供主数据。

## 2. 数据来源与初始化

- 数据来源：租户内所有“自有账号直播间”汇总进入后台直播间列表。
- 初始化规则：
  - 客户端新增直播间：同步直播间基础信息与行业。
  - 归属组织（子公司/部门/小组）：需要在后台维护对应关系。

## 3. 权限边界

- 主账号/超级管理者：可查看/新增/编辑/删除全部直播间。
- 子公司/部门/小组管理者：可查看归属范围内直播间；编辑/删除权限由产品配置（默认建议仅上级管理者可删除）。
- 直播间管理者：可在本直播间范围内进行排班、查看本直播间业绩（不一定可修改归属字段）。

## 4. 直播间主数据字段（摘要）

- 平台：抖音/快手/视频号等。
- 账号 ID：唯一标识，创建时校验“已存在/不存在”。
- 行业：三级级联。
- 首播日期：日期选择。
- 归属组织：子公司（可选）/部门（可选）/小组（可选）。
- 管理者：选择子账号，可多个。
- 监控账号：哪些爱复盘账号录制了该直播间（可多个）。
- 授权状态：巨量/视频号等授权状态展示。
- 业绩统计账号：用于统计该直播间业绩的子账号（可配置）。

## 5. 核心业务能力

### 5.1 直播间列表管理

- 支持按平台、主播名称/直播间名称/ID、行业负责人、所属组织（级联）筛选。
- 列表按创建时间降序展示。
- 列表展示字段：头像+昵称、平台、授权状态、行业、归属组织、监控账号、管理者、操作（编辑/删除）。

### 5.2 新建直播间与管理者

- 创建流程：填写平台/账号 ID/行业/首播日期/归属组织/管理者 → 提交 → 校验结果 → toast 提示。
- 异常：
  - 账号 ID 已存在：提示不可重复创建。
  - 账号 ID 不存在：提示需先在客户端侧完成对应操作或授权（具体文案在 FRD 定义）。

### 5.3 编辑直播间

- 可编辑内容：归属组织（子公司/部门/小组）、管理者、业绩统计账号、监控账号等（以 FRD 为准）。
- 删除直播间：二次确认；删除后的业绩采集规则见业绩模块说明（需求指出“后台没添加的直播间，不采集业绩”）。
