# BRD｜基础设置（角色管理 / 岗位管理 / 套餐限制）

## 1. 模块定位

提供系统级基础配置：角色与权限、岗位列表维护、套餐限制与扩容提示，为人员、直播间、排班、业绩模块提供约束与授权依据。

## 2. 角色管理（系统默认 + 可选自定义）

### 2.1 系统默认角色

- 主账号：所有内容/所有数据。
- 超级管理者：所有内容/所有数据（仅爱复盘子账号可成为超级管理者）。
- 子公司管理者：仅查看负责子公司的数据。
- 部门管理者：仅查看负责部门的数据，可兼多个部门。
- 小组管理者：仅查看负责小组的数据，可兼多个小组/部门。
- 直播间管理者：直播间范围内权限（具体菜单与能力在前端权限文档中定义）。

### 2.2 自定义角色

产品策略：

- 允许添加自定义角色。
- 新角色创建后需分配菜单权限。
- 新角色默认拥有：个人排班、个人业绩（最低可用集）。

### 2.3 管理者选择规则

当组织选择管理者时，只能从更高级级别的管理者账号当中选择（避免“下级管理上级”造成数据越权）。

## 3. 岗位管理

### 3.1 默认岗位

主播、副播、运营、中控、投手、剪辑、嘉宾、合规专员、合规经理、合规负责人。

### 3.2 岗位列表维护

- 编辑：允许修改岗位名称/描述（若影响历史人员数据，需定义兼容策略）。
- 删除：二次确认；若岗位被人员引用，需提示并阻止/迁移（以 FRD 验收为准）。

### 3.3 新增岗位

- 字段：岗位名称、岗位描述。
- 校验：岗位名称不可重复。

## 4. 套餐限制与扩容（摘要）

### 4.1 人员/子公司数量限制

- 企业版：员工≤30；子公司≤1。
- 旗舰版：员工≤50；子公司≤1。
- 集团/定制：员工≤120；子公司不限。

### 4.2 子账号增购价格

工作室 960；企业 480；旗舰 360；集团及以上 180。

### 4.3 提示与拦截

- 达到上限：新增按钮/提交动作拦截；提示升级/扩容引导。
- 录制权限开启：如子账号可绑定数量为 0，引导扩容。
