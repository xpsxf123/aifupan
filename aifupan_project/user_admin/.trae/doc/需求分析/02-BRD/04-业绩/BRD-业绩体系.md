# BRD｜业绩体系（个人/人员/直播间/公司）

## 1. 模块定位

提供多维度业绩分析与追溯：个人业绩、人员业绩、直播间业绩、公司/组织业绩罗盘，并支持数据明细下钻与导出。

## 2. 数据来源与统计口径

### 2.1 数据来源

- 直播间业绩：巨量百应（抖音等）与视频号后台汇总数据。
- 个人业绩：过程数据 + 个人修正（按需求）；用于个人维度展示。
- 人员业绩：智能细分后 + 上传到云空间的场次才统计。
- 场次明细：支持系统采集 + 人工录入（含截图）。

### 2.2 统计口径（关键约束）

- 集团/子公司/部门/小组/直播间：来自平台授权汇总数据（不依赖单场数据）。
- 个人总业绩：录制 + 上传后统计。
- 直播间采集注意：
  - 管理后台未添加的直播间，不采集直播间业绩。
  - 管理后台添加且客户端也添加的直播间：采集本月业绩（从 1 号开始，按开播时间算）。
- 跨天直播的昨日口径：优先取昨日录制场次汇总；8 点做数据修正（详见原文规则）。

## 3. 业绩能力拆分

### 3.1 个人业绩（我的排班和业绩-个人业绩）

- 支持区间：今日/昨日/本周/上周/本月/上月。
- 指标：场观、销售、退款、净销售、投放、ROI（及漏斗趋势切换）。
- 明细：按日期倒序；支持导出 Excel；命名规则：公司+部门+小组+姓名+日期+时间戳.xls。

### 3.2 直播间业绩

#### 3.2.1 直播间业绩列表（业绩汇总/直播间业绩）

- 展示直播间维度的区间汇总（今日/昨日/本周/本月等）。
- 支持编辑归属组织与业绩统计账号。
- 支持查看历史数据。

#### 3.2.2 直播间数据详情

- 概览：区间对比（今日/昨日/本周/上周/本月/上月）。
- 趋势：近 30 天；指标可切换（场观/销售/退款/投放/净销售）；hover 展示 5 值。
- 明细：按日期倒序；支持导出（按版本权限）。

#### 3.2.3 场次汇总

- 按日汇总：场次数量、各角色参与场次统计、总指标汇总。
- 支持跳转查看当日数据汇总与“所有场次”。

#### 3.2.4 直播场次明细（录入/编辑）

- 列表字段：日期、直播时间、人员、指标（场观/销售/退款/净销售/投放/ROI）、数据来源、操作（编辑/删除）。
- 录入规则：
  - 净销售 = 销售 - 退款
  - ROI = 投放产出 / 投放
  - 支持上传截图；根据直播间类型（是否日不落）弹出 1/2 张截图要求
  - 提交前二次确认“本次业绩统计归属到哪些人员角色”（主播/副播默认勾选，中控默认不勾选）

### 3.3 人员业绩（优先级 2）

- 前置依赖：人员管理、场次上传云空间、智能细分。
- 人员列表：按组织与岗位筛选，展示今日/昨日/本周/上周指标与场次数量/时长；支持查看历史数据。
- 人员业绩详情：复用“个人业绩”详情结构（指标、趋势、明细、导出）。

### 3.4 公司业绩罗盘（ing）

- 公司维度概览：5 指标区间对比（今日/昨日/本周/上周/本月/上月）。
- 趋势：近 30 天；指标切换。
- 明细：日期倒序；支持导出（按版本）。
- 下钻：分公司占比（饼图，昨日/近 7 日/近 30 日），支持点击进入分公司详情；Top 部门/小组/直播间可下钻。

## 4. 导出权限

- 企业版：不可导出。
- 旗舰版：可导出。
- 集团/定制版：可导出。
