# BRD｜组织架构与人员管理

## 1. 模块定位

为企业提供组织层级（子公司/部门/小组）与人员档案的集中管理能力，并为排班、业绩统计提供“组织归属、角色权限、录制权限、直播间归属”的基础数据。

## 2. 参与角色与权限边界

- 主账号/超级管理者：可见与可操作全部组织与人员数据。
- 子公司管理者：仅可见/可操作负责子公司范围内的组织与人员（含子公司下部门/小组/人员/直播间）。
- 部门管理者：仅可见/可操作负责部门范围内的人员与直播间归属（可兼多个部门）。
- 小组管理者：仅可见/可操作负责小组范围（可兼多个小组）。
- 直播间管理者：仅可见/可操作负责直播间相关信息（与本模块的关系主要为“被选为管理者”）。

管理者选择规则：

- 组织选择管理者时，只能从更高层级管理者账号中选择。
- 超级管理者仅允许爱复盘子账号担任。

## 3. 组织模型与层级规则

### 3.1 层级定义

- 子公司：可选；集团版/定制版支持创建多个；企业/旗舰仅支持一个子公司或提示升级（按需求文案）。
- 部门：必有；系统存在默认部门。
- 小组：可选；系统存在默认小组。
- 人员：必有。
- 直播间：必有（作为业务对象独立管理，但归属于组织层级）。

### 3.2 组织字段（摘要）

- 子公司：名称、排序、负责人、管理者（多个）、成立日期、备注。
- 部门：名称、归属子公司、排序、负责人（多个）、备注。
- 小组：归属子公司、归属部门、排序、负责人、备注。

## 4. 人员档案与账号规则

### 4.1 人员基础字段

- 头像（必填/可上传修改，具体以 FRD 为准）
- 姓名/昵称（必填）
- 手机号（必填，短信验证）
- 邮箱（选填，需校验）
- 工号（选填）
- 类型（全职/兼职）
- 岗位（单选，来自岗位列表）
- 所属组织（公司-部门-小组，可为空）
- 关联直播间（可为空）

### 4.2 权限字段

- 所属角色：超级管理者/部门管理者/小组管理者/直播间管理者等
- 角色授权策略：部门/小组/直播间管理者需勾选负责范围

### 4.3 录制权限与账号类型

- 账号类型：爱复盘录制/非录制
- 录制权限开关：
  - 开启：占用子账号权限，拥有全套录制与分析能力；需展示已绑定子账号数量/可绑定数量；为 0 时引导扩容。
  - 不开启：登录客户端需拦截并提示文案（由产品定义）。

### 4.4 添加人员的账号归属判断

添加人员时根据手机号判定：

- 未注册：创建为子账号（默认成为租户内子账号）。
- 已是本租户子账号：增加管理后台权限。
- 非本租户爱复盘账号：允许通过短信认证加入（“激活版和免费版可添加”的约束在 FRD 明确为产品策略）。
- 冲突与异常：需给出可操作提示（加入新机构/解绑/不可加入等），以 FRD 验收为准。

### 4.5 删除人员规则

- 删除离职人员时：
  - 若该人员担任任何组织的管理者：需自动解除管理关系或强制更换后才允许删除。
  - 若某组织仅有一个管理者：禁止删除并提示“需更换管理者”。

### 4.6 重置密码规则

支持重置密码；默认密码格式/文案由产品配置（避免在界面明文暴露固定弱密码）。

## 5. 初始化流程（业务口径）

- 无分公司：从部门/小组开始 → 添加成员 → 添加直播间（更新直播间管理者等）。
- 有分公司：从子公司开始 → 添加部门/小组 → 添加成员 → 添加直播间。
- 直播间初始化：同步租户内所有子账号下已录制并标记为“自有”的直播间到直播间管理。

## 6. 会员版本限制（与本模块相关）

- 企业版：员工数≤30；子公司≤1。
- 旗舰版：员工数≤50；子公司≤1。
- 集团/定制版：员工数≤120；子公司不限。
- 达到上限：新增入口拦截并提示升级/扩容。
