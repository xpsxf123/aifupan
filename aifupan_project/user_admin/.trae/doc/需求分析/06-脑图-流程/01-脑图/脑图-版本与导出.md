# 脑图｜版本与导出（整体→大块→小块）

        集团及以上一百八十
      录制权限额度
        开启录制占用额度
        无额度引导扩容
    导出权限
      企业版不可导出
      旗舰可导出
      集团与定制可导出
    上限拦截策略
      新增人员拦截
      新建子公司拦截
      提示升级或扩容
