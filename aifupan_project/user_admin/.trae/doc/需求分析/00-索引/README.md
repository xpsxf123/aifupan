# 测试版-爱复盘管理工具需求拆分（v0）

本目录基于《ing【爱复盘】2.60 管理工具：人员+排班+业绩》需求文档进行结构化拆解，覆盖：

- 整体设计（PRD）→ 模块（BRD）→ 功能（FRD）→ 交互设计（DRD）
- 菜单 → 页面 → 页面功能（前端交互与验收口径）
- Mermaid 脑图 / 流程图
- 原型模型 code 数据（页面结构、交互、布局 JSON）

## 目录导航

- 01-PRD：产品需求总纲（目标、范围、角色、信息架构、全局规则）
- 02-BRD：按业务模块拆分的业务需求（组织/人员、直播间、排班、业绩、商品排行榜、基础设置）
- 03-FRD：按页面/功能点拆分的功能需求（含字段、规则、异常与验收）
- 04-DRD：交互设计文档（信息架构、页面跳转、状态、动效与规范）
- 05-前端：前端文档（菜单-页面-功能、交互、状态共享、权限、接口清单）
- 06-脑图-流程：Mermaid 思维导图与关键流程图
- 07-原型模型：原型模型 code 数据（Markdown 内嵌 JSON）
