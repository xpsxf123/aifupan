# FRD｜商品排行榜

## 1. 页面定位

展示公司（集团/子公司/部门范围）商品销售排名与关键转化指标，支持筛选、下钻与查看商品详情。

## 2. 用户与权限

- 超级管理员/集团管理员：可查看全量数据
- 子公司管理员：仅看本子公司范围
- 部门负责人：仅看本部门范围

## 3. 筛选与搜索

- 商品名称：模糊匹配
- 时间：开始-结束
- 快捷：今日/昨日/近 7 日/近 30 日
- 组织范围：根据权限自动限定（必要时提供下拉展示当前范围）

## 4. 列表字段（集团视角）

- 销售排名（不可隐藏）
- 商品信息（不可隐藏）：商品图 + 商品名 + 单价 + 店铺名
- 来源组织：子公司-部门-小组（无子公司则部门）
- 销量/退单量
- 退款率（默认不展示）
- 销售额/退款额
- 曝光点击率（默认不展示）
- 点击付款率（默认不展示）
- 曝光成交率（默认不展示）
- 千次成交
- 关联直播间
- 关联场次
- 操作：查看商品

## 5. 关键交互

- 点击“查看商品”：进入商品详情页或外链（取决于平台能力）
- 下钻：
  - 从集团→子公司→部门（若支持）
  - 下钻后的数据范围与筛选条件联动

## 6. 状态与异常

- 无数据：提示“当前条件下暂无商品数据（T+1）”
- 时间跨度限制：限制最大跨度并提示
