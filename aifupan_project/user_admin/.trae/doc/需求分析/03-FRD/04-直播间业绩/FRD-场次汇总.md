# FRD｜场次汇总（按日）

## 1. 页面定位

按日汇总展示某直播间在指定时间范围内的直播场次数量、参与人员与汇总指标，支持跳转到当日明细。

## 2. 用户与权限

- 同直播间数据详情页

## 3. 筛选区

- 时间：默认最近一周
- 主播筛选（可选，若需要与明细联动）

## 4. 列表字段

- 日期
- 场次：X 场（点击跳转“当日数据汇总/明细”）
- 人员：按角色汇总（主播/副播/中控/运营等）及各自场次数
- 数据总览：总场观/总销售/总退款/净销售/总投放/投放 ROI
- 操作：
  - 查看所有场次
  - 编辑（原文标注待定，默认不提供入口；若提供则指向“直播场次明细录入/编辑”）

## 5. 状态与异常

- 无场次：提示“当前范围无场次数据”
