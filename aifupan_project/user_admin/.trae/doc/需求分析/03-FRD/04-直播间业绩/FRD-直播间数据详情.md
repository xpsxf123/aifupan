# FRD｜直播间数据详情

## 1. 页面定位

展示单个直播间的区间概览、趋势与明细，支持导出（按版本），并提供场次汇总与场次明细入口。

## 2. 用户与权限

- 查看：按组织/直播间权限范围
- 导出：旗舰/集团/定制可导出；企业不可导出

## 3. 基础信息区

- 直播间头像/名称/ID
- 所属组织
- 管理员

## 4. 数据概览（对比）

展示 6 个指标在：今日/昨日/本周/上周/本月/上月的值与对比趋势（上升/下降/同比环比表现形式由 UI 定义）。指标：场观、销售、退款、净销售、投放、投放 ROI。

## 5. 数据趋势

- 默认时间范围：近 30 天（结束=昨日，开始=昨日-30）
- 时间段可选：选择后趋势与明细同步变化
- 指标切换：场观/销售/退款/投放/净销售（默认场观）
- 图表：柱状图
  - X 轴：日期
  - Y 轴：值（按指标动态刻度）
  - hover：展示 5 个值详情

## 6. 数据明细

- 表格按日期倒序
- 支持导出：
  - 文件名：直播间名称 + 日期区间 + 数据详情
  - 企业版点击导出：提示无权限

## 7. 关联入口

- 场次汇总（按日汇总）
- 直播场次明细（录入/编辑）
