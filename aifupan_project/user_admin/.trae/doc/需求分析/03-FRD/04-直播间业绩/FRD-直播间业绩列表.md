# FRD｜直播间业绩列表

## 1. 页面定位

展示直播间维度的业绩汇总列表（T+1/平台口径），支持按组织筛选、查看详情、编辑归属与业绩统计账号、查看历史数据。

## 2. 用户与权限

- 超管/集团/组织管理者：可查看范围内全部直播间业绩。
- 部门/小组/直播间管理者：仅可查看归属范围内数据。

## 3. 表头说明

- 仅统计“已上传云空间的场次业绩”进入本业绩表（原文说明）；与平台汇总口径并存时需明确：此表是否为“平台汇总 + 账号统计”或“场次汇总”，实现前需确认。

## 4. 筛选区

- 平台
- 按部门筛选（有默认部门）
- 按小组筛选（有默认小组）

## 5. 列表字段

- 直播间：头像+昵称
- 平台：抖音/视频号/快手
- 平台授权：巨量已授权/视频号已授权
- 小组：子公司-部门-小组
- 今日数据：直播 X 场、场观、销售、退款、净销售、投放
- 昨日数据：同上
- 本周总数据：同上
- 本月总数据：同上
- 排班：本周已排/本月已排
- 业绩统计账号：子账号昵称+手机号（可多）
- 操作：编辑 / 查看历史数据 / 查看详情

## 6. 编辑

- 支持修改：部门、小组、业绩统计账号（哪个爱复盘账号统计）
- 保存成功 toast；失败提示

## 7. 验收标准（节选）

- 筛选条件影响列表数据范围与字段正确展示。
- 编辑后归属与统计账号在列表与详情页一致更新。
