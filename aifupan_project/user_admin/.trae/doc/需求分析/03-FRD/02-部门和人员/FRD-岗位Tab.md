# FRD｜部门和人员-岗位（Tab）

## 1. 页面定位

维护本公司岗位列表，供人员档案选择岗位使用。

## 2. 用户与权限

- 权限：超级管理员（默认）。

## 3. 岗位列表

### 3.1 默认岗位

主播、副播、运营、中控、投手、剪辑、嘉宾、合规专员、合规经理、合规负责人。

### 3.2 列表字段

- 岗位名称
- 岗位描述（可选）
- 操作：编辑/删除

### 3.3 删除规则

- 二次确认必需
- 若岗位被人员引用：提示并阻止删除或要求先迁移（具体策略需产品确认并在此页验收）

## 4. 新增岗位

- 字段：岗位名称（必填）、岗位描述
- 校验：岗位名称不可重复
- 成功 toast：新增成功
