# FRD｜部门和人员（Tab 容器页）

## 1. 页面定位

企业管理者在同一页面下，通过 Tab 管理组织机构与核心主数据：人员、直播间、小组/部门、子公司、岗位。

## 2. 用户与权限

- 可见/可操作：主账号、超级管理者（原文明确）。
- 其他管理者是否可见该页：建议按权限系统配置（默认仅超管可进入）。

## 3. 页面结构

- 顶部：公司名称（默认机构公司名）
- Tab：人员 / 直播间 / 小组和部门 / 子公司 / 岗位
- Tab 间切换：保留筛选条件策略（默认“各 Tab 独立保存最近一次筛选”）

## 4. 初始化引导

根据租户是否有子公司：

- 无分公司：从部门/小组开始 → 添加成员 → 添加直播间（并更新直播间管理者等）。
- 有分公司：从子公司开始 → 添加部门/小组 → 添加成员 → 添加直播间。

## 5. 通用交互与状态

- 空状态：无数据时显示“暂无数据/请先创建XX”
- 版本限制：创建子公司/导出等能力需按版本提示与拦截
