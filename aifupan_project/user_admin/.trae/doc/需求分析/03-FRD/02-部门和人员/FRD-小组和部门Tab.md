# FRD｜部门和人员-小组和部门（Tab）

## 1. 页面定位

以组织层级（子公司+部门+小组）管理组织结构，支持展开查看、创建部门/小组、编辑与删除，并展示组织下直播间数量与管理者。

## 2. 用户与权限

- 权限：超级管理员（默认）。

## 3. 筛选区

- 所属公司 / 所属部门 / 所属小组（级联）
- 负责人名称（输入框）

## 4. 列表区（树形/可展开）

### 4.1 层级

- 子公司（可选）→ 部门 → 小组

### 4.2 列表字段

- 组织名称（可展开/收起）
- 组织类型：部门/小组
- 所属公司
- 归属直播间：组织下直播间数量
- 管理员：名称 + 手机号（隐藏中间 4 位）
- 操作：
  - 部门：查看/编辑/删除/添加小组
  - 小组：查看/编辑/删除

### 4.3 默认展开与命名

- 若只有一个公司：默认展开部门。
- 组织名称默认=部门名称，类型=部门（系统默认组织）。

## 5. 新建部门（弹窗/抽屉）

字段：

- 所属分公司：仅旗舰版及以上；默认带出公司名称
- 排序：默认从 1 开始
- 部门名称：必填
- 组织类型：默认“部门”，不可选其他
- 组织备注：文本
- 管理者：选择子账号（可多选，最多 X 个）提交：
- 成功 toast：XXX 部门创建成功
- 失败：提示原因（重名/权限/版本限制等）

## 6. 新建小组（弹窗/抽屉）

字段：

- 上级组织：默认带出公司名称与部门名称
- 排序：默认从 1 开始
- 组织名称：必填
- 组织类型：默认“小组”，不可选其他
- 组织备注：文本
- 管理者：选择子账号（可多选）提交：
- 成功 toast（文案按产品统一）

## 7. 编辑与删除

- 编辑：允许修改名称、排序、备注、管理者（组织归属约束按层级）
- 删除：
  - 二次确认必需
  - 若组织仍有关联直播间/人员/唯一管理者等需提示并阻止（细则在 BRD/权限策略中落地）
