# FRD｜部门和人员-子公司（Tab）

## 1. 页面定位

集团版/定制版客户管理子公司；企业/旗舰版在子公司能力上受限并展示引导提示。

## 2. 用户与权限

- 权限：超级管理员（默认）。

## 3. 版本与展示逻辑

- 非集团版与非定制版：提示“仅可创建一个子公司/需升级后创建多个”（按产品文案）。
- 定制版/集团版：展示子公司列表与操作。

## 4. 列表（集团/定制）

- 字段：
  - 公司名称
  - 管理员：名称 + 手机号
  - 操作：查看/编辑/解散公司

## 5. 新建子公司（集团/定制）

字段（参考原文口径）：

- 子公司名称（必填）
- 排序
- 负责人
- 管理者（多个）
- 成立日期
- 备注提交：
- 成功 toast
- 校验：名称不重复、管理者选择规则（只能从更高层级选）

## 6. 解散子公司

- 二次确认必需
- 约束：若子公司下仍有部门/人员/直播间，需提示处理路径（迁移或先清空）
