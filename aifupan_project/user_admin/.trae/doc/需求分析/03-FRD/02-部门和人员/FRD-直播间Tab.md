# FRD｜部门和人员-直播间（Tab）

## 1. 页面定位

在组织管理容器页中管理直播间主数据：列表查看、筛选、编辑归属组织与管理者等。

## 2. 用户与权限

- 权限：超级管理员（默认）。

## 3. 筛选区

- 平台（下拉：抖音/快手/视频号等）
- 主播/直播间名称/ID（输入框）
- 行业负责人名称（输入框）
- 所属组织：公司/部门/小组（级联）

## 4. 列表区

- 列表标题：直播间（数量 XXX）
- 排序：创建时间降序
- 字段：
  - 直播间：头像+昵称
  - 平台：平台 logo
  - 授权状态：巨量/视频号授权状态
  - 行业：展示第一个添加的行业
  - 归属：公司/部门/小组
  - 监控账号：录制该直播间的爱复盘账号（可多个）
  - 管理者：昵称 + 手机号（中间 4 位隐藏）
  - 操作：编辑/删除

## 5. 新建直播间

- 入口：跳转到“新建直播间+管理者”（同直播间管理模块）
- 创建字段：平台、账号 ID、行业三级级联、首播日期、所属组织、管理者（可多个）
- 创建校验：
  - 账号 ID 唯一
  - 账号 ID 不存在/不可创建时提示原因

## 6. 编辑直播间

- 可编辑：
  - 所属组织（子公司/部门/小组）
  - 管理者
  - 业绩统计账号（若在此页承载）
- 保存成功 toast；失败提示原因。

## 7. 删除直播间

- 二次确认必需
- 删除后的业绩采集规则：后台未添加则不采集（提示风险）
