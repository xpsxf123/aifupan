# FRD｜人员业绩列表（人员业绩和排班-人员业绩）

## 1. 页面定位

按成员维度统计业绩（依赖智能细分+上传云空间），提供筛选、指标概览、场次统计，并可进入人员业绩详情。

## 2. 前置依赖

- 人员管理已建立人员档案与组织归属
- 场次已上传到云空间
- 智能细分已完成

## 3. 用户与权限

- 主账号/超级管理者：可查看全量人员
- 组织管理者：仅可查看负责范围内人员

## 4. 筛选区

- 所属公司/部门/小组
- 岗位（下拉）
- 姓名（输入框）
- 手机号码（输入框）

## 5. 列表字段

- 姓名
- 岗位：主播/助播等
- 类型：兼职/全职
- 所属部门：公司-部门-小组
- 所属直播间（若有绑定）
- 指标：
  - 今日业绩 / 昨日 / 本周 / 上周：场观、销售、退款（及必要指标）
- 明细场次：
  - 场次数量
  - 累计场次时长
- 操作：查看历史数据 / 查看详情

## 6. 状态与异常

- 无数据：提示“暂无可统计人员业绩（请先完成智能细分与上传）”
