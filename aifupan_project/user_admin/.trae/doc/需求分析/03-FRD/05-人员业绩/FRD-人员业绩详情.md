# FRD｜人员业绩详情

## 1. 页面定位

查看某个成员在指定时间范围内的业绩详情、趋势与明细；页面结构与“个人业绩”一致，但查看对象为被选人员。

## 2. 用户与权限

- 可见：主账号/超级管理者/组织管理者（在其数据范围内）
- 数据范围：必须满足组织权限（跨部门/跨子公司需拦截）

## 3. 页面结构

- 成员基础信息：姓名/岗位/组织
- 区间汇总：今日/昨日/本周/上周/本月/上月
- 趋势图：指标切换（场观/销售/退款/投放/转化等）
- 明细表：日期倒序；支持导出（按版本）

## 4. 数据规则

- 业绩来源：智能细分后 + 上传云空间的场次
- 若数据不全：展示缺失原因（未上传/未细分/无场次等）
