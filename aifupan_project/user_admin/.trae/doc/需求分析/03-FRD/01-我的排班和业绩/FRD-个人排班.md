# FRD｜个人排班（我的排班和业绩-个人排班）

## 1. 页面定位

员工查看自己的排班信息，并以“快捷汇总 + 周日历小时视图”理解未来与历史排班，支持进入直播间当日排班详情查看。

## 2. 用户与权限

- 可见角色：主账号、超级管理者、子公司/部门/小组/直播间管理者、普通员工（按需求表述均可进入“我的排班和业绩”）。
- 仅查看：普通员工默认仅查看自己；管理者可扩展查看范围以产品策略为准（原文中“看所有/看自己”筛选已划线，暂不做）。

## 3. 页面结构

### 3.1 个人基础信息区

- 头像 + 昵称/姓名 + 岗位 + 手机号

### 3.2 近期排班汇总（快捷入口）

- 今日排班：展示当日排班列表（直播间、角色、时间）并支持“查看详情”
- 明日排班：同上
- 昨日/本周/下周/本月：提供查看入口（可跳转到对应时间范围）

### 3.3 个人排班列表（日历小时视图）

定位：以“自然周”为单位展示排班，按 24 小时横轴粒度展示排班块。

- 表头：0-23 小时，默认展示 0-12；支持左右拖动展示后续时间；拖动时左侧日期保持固定。
- 左侧：周一到周日
  - 日期状态：过去（灰）、当前日（紫）、未来（黑）
- 排班块显示：
  - 信息：直播间、开始-结束、总时长
  - 视觉：已过去排班/进行中及未来排班使用不同颜色（由视觉稿定义）
- 右侧切换：默认“本月”；可切换下周/本月/下月（与视图联动）

## 4. 关键交互

### 4.1 查看排班详情

触发：点击排班色块或 hover（按需求）

- hover：展示该排班摘要（直播间、时间、角色）
- 点击：进入/弹出“直播间当日排班详情”（同直播间排班详情中的当日视角）

### 4.2 时间范围切换

切换项：明日/今日/昨日/本周/下周/本月（来自快捷入口或右侧切换）

- 切换后：周视图的起止日期与排班块更新

## 5. 数据与规则

### 5.1 数据来源

- 来自“直播间排班总表”中与当前用户匹配的排班记录。

### 5.2 排班块生成规则

- 一个排班记录映射为一个色块，跨小时覆盖对应区间。
- 若跨天：按自然日切割（建议按日期拆分多个块，以免跨列显示异常）。

## 6. 状态与异常

- 空状态：当期范围无排班 → 显示“暂无排班/未排班”提示。
- 加载态：骨架屏或加载动画。
- 权限态：无权限访问 → 提示并引导返回默认菜单。

## 7. 验收标准（节选）

- 能正确展示本周（周一-周日）排班，24 小时横轴可拖动。
- 点击任一排班块能展示/跳转到该直播间当日排班信息。
- 快捷入口切换时间范围后，列表数据与标题范围同步更新。
