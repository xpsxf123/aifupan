# FRD｜个人业绩（我的排班和业绩-个人业绩）

## 1. 页面定位

员工查看自己的业绩数据与趋势，支持区间对比、明细下钻与导出。

## 2. 用户与权限

- 可见：普通员工与各级管理者（查看范围以权限策略为准，默认仅个人视角）。

## 3. 页面结构

### 3.1 个人基础信息

- 岗位、人员昵称/姓名、组织信息（公司/部门/小组）

### 3.2 区间汇总卡片

区间：今日、昨日、本周、上周、本月、上月指标（每区间均展示）：

- 场观
- 销售
- 退款
- 净销售
- 投放
- ROI

### 3.3 对比数据

能力：与昨日/本周/上周/本月/上月做对比（表格或卡片），并支持按日期区间选择（常用跨度产品定义）。

### 3.4 主播数据分析（趋势图）

- 形式：漏斗模型趋势图
- 指标切换：场观/销售额/退款/投放/成交转化率
- 时间范围：与页面顶部区间选择联动

### 3.5 数据详情（明细表）

- 按日期展示明细，日期排序：降序
- 是否分页：由产品定义（建议分页）
- 导出：支持导出到 Excel
  - 文件命名：公司+部门+小组+姓名+日期+时间戳.xls
  - 数字格式：场观按大数规则（>1万显示 XX.XX万）；金额/百分比保留 2 位小数

## 4. 关键交互

- 区间切换：更新汇总卡片、趋势图与明细表
- 指标切换：趋势图与 hover 提示更新
- 导出：按当前筛选区间导出

## 5. 数据规则

- 数据源：过程数据 + 个人修正（按需求）；与直播间汇总数据存在口径差异需在页面说明中提示。
- 依赖：已上传到云空间的场次数据才可形成完整统计（若不满足需提示原因）。

## 6. 状态与异常

- 无数据：提示“暂无业绩数据/请先完成录制并上传”等说明
- 导出限制：企业版不可导出（若此页也受版本限制，以统一策略为准）
- 时间跨度过大：限制最大跨度并提示

## 7. 验收标准（节选）

- 区间切换后 5-6 个指标值、趋势图与明细表一致更新。
- 导出文件名符合命名规则且数据列顺序、格式符合要求。
