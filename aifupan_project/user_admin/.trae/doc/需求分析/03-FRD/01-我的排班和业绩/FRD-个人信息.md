# FRD｜个人信息（我的排班和业绩-个人信息）

## 1. 页面定位

员工查看并维护个人基础资料（头像、联系方式、组织与角色展示等）。

## 2. 用户与权限

- 可见：所有可登录后台的账号。
- 可编辑：本人可编辑个人资料字段；管理者是否可代编辑由产品策略确定（默认不支持代编辑）。

## 3. 字段与交互

### 3.1 个人基础信息

- 头像：支持上传与修改
- 手机号：展示（是否允许修改需产品定义；若允许需短信校验）
- 邮箱：输入/修改，需邮箱格式校验
- 组织信息：子公司/部门/小组/直播间（只读展示）
- 角色信息：管理权限相关信息（只读展示）
- 岗位：展示（是否允许修改建议走管理端人员编辑）

### 3.2 保存

- 点击保存后校验必填与格式；成功 toast；失败提示具体原因。

## 4. 状态与异常

- 上传失败：提示重试与原因（大小/格式/网络）
- 邮箱校验失败：提示输入正确邮箱

## 5. 验收标准（节选）

- 头像上传成功后立即回显并持久化。
- 邮箱校验规则生效；保存失败时展示明确错误信息。
