# FRD｜按组织查看直播间业绩（业绩汇总-按不同组织查看）

## 1. 页面定位

在集团/子公司/部门/小组维度下，按组织展示直播间业绩列表，并提供“查看每日业绩”下钻。

## 2. 数据采集注意

- 后台没添加的直播间不采集直播间业绩。
- 后台添加且客户端也添加：采集本月（从 1 号开始，按开播时间）。

## 3. 用户与权限

- 超级管理员：可看所有组织
- 子公司/部门/小组管理者：仅可见负责范围
- 导出：按版本策略

## 4. 筛选区

- 时间范围：某日/昨日/本周/本月（默认今日）
- 分公司筛选（若存在）
- 部门筛选
- “按小组查看”切换（若为部门维度）

## 5. 组织汇总区

展示组织卡片：部门/分公司名称、总场观、总销售额、查看部门每日业绩入口、部门管理者信息等。

## 6. 列表字段（直播间维度）

- 直播间：账号昵称 + ID + 平台
- 小组：小组名称
- 时间段：今日/昨日/本周/本月
- 班次/场次：X 班或 X 场
- 总场观
- 总销售
- 总退款
- 净销售
- 总投放
- 投放 ROI
- 操作：查看每日业绩

## 7. 状态与异常

- 无数据：提示“当前条件下暂无直播间数据”
- 权限不足：隐藏组织筛选或提示无权限
