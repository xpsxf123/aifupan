# FRD｜公司业绩罗盘（业绩汇总-公司业绩罗盘）

## 1. 页面定位

以公司维度展示全量直播间的关键指标概览、趋势与明细，并支持按子公司/部门/小组/直播间下钻查看。

## 2. 用户与权限

- 超级管理员/集团管理员：可查看全量
- 子公司管理者：仅看负责子公司
- 部门/小组管理者：仅看负责范围
- 导出：企业不可导出；旗舰/集团/定制可导出

## 3. 页面结构

### 3.1 数据概览

展示 5 个指标在今日/昨日/本周/上周/本月/上月的对比情况：场观、销售、退款、净销售、投放（ROI 可作为附加）。

### 3.2 数据趋势

- 默认近 30 天（结束=昨日）
- 指标切换：场观/销售/退款/投放/净销售
- hover 展示 5 值详情

### 3.3 数据明细

- 日期倒序明细表
- 导出：文件名=公司名称+日期区间+数据详情

### 3.4 分公司明细（饼图 + 列表）

- 饼图：展示分公司占比
- 时间切换：昨日/近 7 日/近 30 日
- 点击分公司：进入“分公司业绩详情”（可复用同页下钻面板）

### 3.5 Top 部门/小组/直播间

- 展示 Top 列表（按指标）
- 支持点击进入组织详情/直播间详情

## 4. 数据口径提示

明确提示：本页统计来自平台授权汇总（不依赖单场录入），与人员业绩口径不同。
