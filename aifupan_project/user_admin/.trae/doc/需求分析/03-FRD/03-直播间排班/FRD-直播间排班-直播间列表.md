# FRD｜直播间排班-直播间列表

## 1. 页面定位

直播间管理者/管理者查看自有直播间列表，并快速查看今日/明日/本周/本月排班状态，进入排班详情或进行首次排班配置。

## 2. 用户与权限

- 直播间管理者：默认只看负责直播间。
- 主账号/超级管理者/组织管理者：可看范围内直播间并可编辑排班。

## 3. 筛选区

- 平台：下拉
- 搜索直播间：直播间名称/ID（模糊）
- 行业负责人
- 组织：公司-部门-小组（级联）

## 4. 列表区

- 字段：
  - 直播间：头像+昵称
  - 平台
  - 小组：组织名称
  - 今日排班：未排班→“添加排班”，已排班→“查看排班”
  - 明日排班：同上
  - 本周排班：查看排班
  - 下周排班：查看排班
  - 本月排班：查看排班
- 是否排班指标：
  - 今日/明日：当日排班比例 > X%（阈值产品配置）
  - 本周/下周/本月：展示“查看”

## 5. 关键交互

- 添加排班：进入“直播间排班详情”并定位到对应日期/区域
- 查看排班：进入“直播间排班详情”
- 添加直播间：跳转到“新建直播间+管理者”

## 6. 状态与异常

- 无直播间：提示引导添加直播间
- 无排班权限：隐藏“添加排班”入口或提示无权限
