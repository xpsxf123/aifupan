# FRD｜直播间首次排班配置

## 1. 页面定位

直播间首次排班时配置“时间轴与分隔规则”，影响排班编辑体验与场次/业绩拆分口径；支持复制其他直播间配置。

## 2. 用户与权限

- 主账号/超级管理者/直播间管理者（建议可配置，最终以权限策略为准）。

## 3. 页面结构与字段

### 3.1 复制直播间配置

- 若本机构下存在已编辑过时间轴的直播间：展示“复制直播间”入口
- 弹窗：选择直播间 → 将其配置值复制到表单 → 允许修改 → 保存后生效

### 3.2 直播模式

来源：取上传业绩的爱复盘子账号（原文疑问点）；需在实现时明确口径（例如：选择“业绩统计账号”作为模式来源）。

### 3.3 班次配置

- 每日开始时间：默认 00:00，可修改；或“不限”（日不落）
- 每日结束时间：默认 24:00，可修改；或“不限”（日不落）
- 每个班次时长：X 小时 X 分钟
  - 支持添加多个时长选项（如 2h/3h/4h）

### 3.4 时间轴单位

默认 60 分钟，可选：120/60/30/15 分钟

### 3.5 中间休息时长

- 默认“不休息”
- 选择“休息”后：可选择休息时长

### 3.6 岗位配置

- 默认：主播/中控/副播
- 支持增加/减少岗位

## 4. 录制说明（页面提示文案）

1. 日不落直播间（>24h）：开始/结束时间请选择“不限”
2. 班次时长不定且连续开播：通过“切割班次”按钮分割场次与业绩
3. 切割班次逻辑：

- 不休息：每班次结束停止录制并分段
- 休息：每班次结束自动分段但不停止录制，直到下播

## 5. 保存与生效

- 保存成功 toast
- 生效范围：该直播间后续排班编辑与场次/业绩拆分使用此规则

## 6. 状态与异常

- 无可复制直播间：隐藏复制入口
- 校验：开始/结束时间合理；时长>0；岗位至少 1 个
