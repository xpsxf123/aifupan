# 客户端拉取商品数据

> **所属服务：Windows 桌面客户端（ReviewAnalysis）**

## 接口信息

| 项目 | 内容 |
|---|---|
| 路径 | `/api/anchorvideo/pullProduct` |
| 方法 | `POST` |
| Content-Type | `application/json` |
| 说明 | 本地 HTTP 接口（`HttpListener`），供企业后台调用，触发客户端从平台拉取商品数据 |

## 请求参数（JSON Body）

| 参数 | 类型 | 必填 | 说明 |
|---|---|---|---|
| secUid | String | 是 | 主播唯一标识 |
| batchNumber | String | 是 | 直播批次号 |

## 返回字段说明

| 字段 | 类型 | 说明 |
|---|---|---|
| code | Integer | 状态码，0=成功 |
| msg | String | 提示信息 |
| data | null | 无返回数据 |

## 请求示例

```json
POST /api/anchorvideo/pullProduct

{
  "secUid": "2200756289440511",
  "batchNumber": "20260728_001"
}
```

## 返回值示例

```json
{
  "code": 0,
  "msg": "成功",
  "data": null
}
```
