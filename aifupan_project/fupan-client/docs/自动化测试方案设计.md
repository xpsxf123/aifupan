# 自动化测试方案设计

## 一、目标与范围

### 1.1 核心目标

构建一套**前端真实运行环境下的自动化测试体系**，覆盖三个维度：

| 维度 | 说明 | 目标 |
|------|------|------|
| 接口链路测试 | 多接口链式调用 + 参数流 + 异常分支 | 保证接口调用顺序、参数传递、错误处理正确 |
| 交互内容测试 | DOM 变更抓取 + 内容断言 | 保证渲染内容与接口数据一致、条件渲染正确 |
| 视觉回归 | 人工过一遍样式 + 后续接入图像模型 | 当前仅人工，后续可扩展 |

### 1.2 不做的事

- **不追求像素级视觉回归**（当前阶段人工确认样式即可）
- **不替代后端接口测试**（只验证前端调用链和处理逻辑）
- **不做单元测试级别的白盒覆盖**（聚焦集成 / E2E 级别的真实环境验证）

### 2.1 两种运行模式

| 模式 | 运行环境 | 适用场景 |
|------|---------|---------|
| **独立页面模式** | 独立的 HTML 页面，仅加载请求层，不渲染 Vue 组件 | 接口参数流测试、纯 API 链路验证 |

## 三、模块一：API 链式调用引擎

### 3.1 目标

在**独立 HTML 页面**中模拟多接口的链式调用，自动处理参数依赖传递和异常分支。

### 3.2 核心设计

```javascript
// test-chain.config.js — 接口链路配置
export default {
  name: '商品列表 → 拉取商品 → 查询商品分页',
  env: 'test',  // test | production
  baseURL: 'window.SITE_CONFIG.backApiURL',  // 或直接写死测试环境地址

  // 全局前置 Mock：模拟 Vue 原型上挂载的全局变量
  globals: {
    '$store.getters.getUserInfo': { nickName: 'test', tenantId: 'xxx' },
    '$auth': () => true,
    'window.SITE_CONFIG': { backApiURL: 'https://test-api.xxx.com' }
  },

  // 测试步骤链
  steps: [
    {
      id: 'step-1',
      name: '获取商品分页列表',
      // 接口映射：直接引用项目中的 API 聚合方法
      api: '$httpBack2.liveRoom.productPage',
      payload: {
        batchNumber: '{{ input.batchNumber }}',   // 外部入参
        videoId: '{{ input.videoId }}',
        page: 1,
        limit: 10
      },
      // 断言规则
      asserts: [
        { type: 'code-equal', value: 0 },
        { type: 'data-has-keys', keys: ['records', 'total'] },
        { type: 'data-non-empty', path: 'records' }
      ],
      // 提取变量，供后续步骤使用
      extract: {
        firstProductTitle: 'data.records[0].title',
        firstProductId: 'data.records[0].id',
        totalCount: 'data.total'
      }
    },
    {
      id: 'step-2',
      name: '按商品标题搜索',
      api: '$httpBack2.liveRoom.productPage',
      payload: {
        batchNumber: '{{ input.batchNumber }}',
        videoId: '{{ input.videoId }}',
        page: 1,
        limit: 10,
        title: '{{ step-1.firstProductTitle }}'  // 引用上一步提取的变量
      },
      asserts: [
        { type: 'code-equal', value: 0 },
        { type: 'data-property-match', path: 'records[0].title', value: '{{ step-1.firstProductTitle }}' }
      ]
    }
  ]
}
```

### 3.3 实现要点

1. **API 懒加载**：通过 `Function('return ' + apiPath)` 动态获取项目请求方法，避免全量打包
2. **参数模板引擎**：支持 `{{ stepId.varPath }}`、`{{ input.xxx }}`、`{{ env.xxx }}` 三种变量源
3. **串行 + 并行**：默认串行，配置 `parallel: true` 的步骤组并行执行
4. **错误分支**：配置 `onError: 'continue' | 'skip' | 'stop'` 控制失败后行为
5. **重试机制**：`retry: 3, retryDelay: 1000`

## 四、模块二：DOM 抓取与分析引擎

### 4.1 目标

在**真实项目页面**中，每次接口请求完成后自动抓取目标容器的 HTML / innerText，并做内容断言。

### 4.2 核心设计

```javascript
  // 容器选择器映射（基于项目现有 class 命名规范）
  selectors: {
    // 商品列表
    productTable: '.productData-table',
    productRows: '.productData-table .el-table__body tr',
    productEmpty: '.productData-empty',
    productEmptyText: '.productData-empty__text',

    // AI 助手区域
    aiBox: '.ai-box',
    aiAssistantHeader: '.aiAssistantHeader',
    // 通用
    loading: '.el-loading-mask',
    messageBox: '.el-message-box',
    dialog: '.el-dialog'
  },

  // 抓取规则
  captureRules: [
    {
      name: '商品列表-表格存在',
      trigger: 'after-api:productPage',
      selector: 'productTable',
      asserts: [
        { type: 'exists' },
        { type: 'child-count-min', selector: 'productRows', min: 1 }
      ]
    },
    {
      name: '商品列表-空状态',
      trigger: 'after-api:productPage',
      when: { 'step-1.totalCount': 0 },  // 条件触发
      selector: 'productEmpty',
      asserts: [
        { type: 'exists' },
        { type: 'text-contains', text: '暂无商品数据' }
      ]
    },
    {
      name: '数据看板-加载完成',
      trigger: 'after-api:infoByVideoId',
      selector: 'dataBoardContainer',
      preCondition: { selector: 'loading', assert: 'not-exists' },  // 前置条件
      asserts: [
        { type: 'exists' },
        { type: 'no-element', selector: 'loading' }
      ]
    }
  ]
}
```

### 4.3 MutationObserver 集成

```javascript
class DomCaptureEngine {
  constructor(config) {
    this.config = config
    this.snapshots = []
    this.observer = null
  }

  start() {
    this.observer = new MutationObserver((mutations) => {
      // 防抖：300ms 内只处理一次
      clearTimeout(this._debounceTimer)
      this._debounceTimer = setTimeout(() => {
        this.checkRules()
      }, 300)
    })

    this.observer.observe(document.body, {
      childList: true,
      subtree: true,
      attributes: true
    })
  }

  checkRules() {
    const triggeredRules = this.config.captureRules.filter(
      rule => this.shouldTrigger(rule)
    )
    triggeredRules.forEach(rule => this.executeRule(rule))
  }

  executeRule(rule) {
    const element = this.resolveSelector(rule.selector)
    const snapshot = {
      rule: rule.name,
      timestamp: Date.now(),
      html: element?.outerHTML,
      text: element?.innerText,
      exists: !!element,
      children: element?.querySelectorAll('*').length
    }
    this.snapshots.push(snapshot)
    this.runAsserts(rule.asserts, snapshot)
  }
}
```

### 4.4 与接口引擎联动

```
API 执行完成
    │
    ├──→ 触发 `after-api:{apiName}` 事件
    │       │
    │       ▼
    │    DOM-Capture 检查对应规则
    │       │
    │       ├──→ 前置条件满足 → 执行抓取 + 断言
    │       └──→ 前置条件不满足 → 跳过
    │
    └──→ 记录本次 API + DOM 快照到测试报告
```

## 八、技术选型

### 8.1 不引入第三方测试框架

**原因**：
- 项目零测试基础设施，引入 Vitest / Jest / Cypress 需要大量配置
- 项目基于 Vue CLI 4.x + Webpack，与 Vite 生态不兼容
- 本方案的核心是**运行时注入**，不是构建时测试

### 8.2 纯运行时方案

| 组件 | 技术方案 |
|------|---------|
| 接口链式调用 | 直接复用 `$httpBack` / `$httpBack2` / `$httpClient` |
| DOM 抓取 | 原生 `MutationObserver` + `querySelector` |
| UI 模拟 | 原生 DOM 事件触发（`click()`、`dispatchEvent`） |
| 参数模板 | 简单正则替换 `/\{\{\s*([\w.-]+)\s*\}\}/g` |
| 报告生成 | 纯 JS 构造 JSON + 渲染 HTML |
| 独立页面 | 单独 HTML + CDN Vue 2（不依赖项目构建） |

### 8.3 环境注入方式

```
开发环境 (npm run serve):
  App.vue / main.js 判断 ?test-mode=1 参数
    → 动态 import('@/test-engine')
    → 挂载测试面板到页面右下角

独立页面:
  直接打开 api-chain-tester.html
    → 手动指定测试环境 baseURL
    → 加载项目的请求封装模块
```

## 十、关键技术细节

### 10.1 API 懒加载方式

```javascript
// api-loader.js
export function resolveApi(apiPath) {
  // apiPath 示例: '$httpBack2.liveRoom.productPage'
  const parts = apiPath.split('.')
  const rootName = parts[0]  // '$httpBack2'

  // 动态获取挂载在 Vue.prototype 上的请求实例
  const root = window.__VUE_APP__?.config?.globalProperties?.[rootName]
    || Vue.prototype[rootName]

  if (!root) throw new Error(`API root "${rootName}" not found`)

  // 逐级访问嵌套属性
  return parts.slice(1).reduce((obj, key) => obj?.[key], root)
}
```

### 10.3 Element UI 组件交互

```javascript
// 处理 Element UI 的非原生 DOM 结构
class ElementUIActionHelper {
  // el-radio 点击
  static clickRadio(selector, value) {
    const radio = document.querySelector(`${selector} .el-radio__input [value="${value}"]`)
    radio?.click()
  }

  // el-select 选择
  static selectOption(selector, optionText) {
    const select = document.querySelector(selector)
    select?.click()  // 打开下拉
    setTimeout(() => {
      const option = [...document.querySelectorAll('.el-select-dropdown__item')]
        .find(el => el.textContent.includes(optionText))
      option?.click()  // 会触发 v-model 更新
    }, 200)
  }

  // el-table 排序
  static clickSort(columnSelector) {
    const caret = document.querySelector(`${columnSelector} .caret-wrapper`)
    caret?.click()
  }
}
```
