# 获取主播授权状态

> **所属服务：爱复盘后台（fupan-server）**

## 接口信息

| 项目 | 内容 |
|---|---|
| 路径 | `/replay/words/anchorUrl/getAuthStatus` |
| 方法 | `GET` |
| 鉴权 | 需登录（Bearer Token） |

## 请求参数

| 参数 | 类型 | 必填 | 位置 | 说明 |
|---|---|---|---|---|
| secUid | String | 是 | Query | 主播唯一标识 |

## 返回字段说明

| 字段 | 类型 | 说明 |
|---|---|---|
| code | Integer | 状态码，0=成功，30000=记录不存在 |
| msg | String | 提示信息 |
| data | Object | 授权状态对象，不存在时为 null |
| data.anchorUrlSecUid | String | 主播 SecUid |
| data.authJlbyStatus | Integer | 巨量百应授权状态：0-未授权, 1-已授权, 2-授权过期, 3-授权失败, 4-授权中, 5-授权抖音号不匹配 |
| data.authJlbyStatusTime | String | 巨量百应授权状态修改时间（yyyy-MM-dd HH:mm:ss） |
| data.authQcStatus | Integer | 千川授权状态：0-未授权, 1-已授权, 2-授权过期, 3-授权失败, 4-授权中, 5-授权抖音号不匹配 |
| data.authQcStatusTime | String | 千川授权状态修改时间（yyyy-MM-dd HH:mm:ss） |
| data.authChannelStatus | Integer | 微信视频号授权状态：0-未授权, 1-已授权, 2-微信后台取消授权, 3-用户取消授权 |
| data.authLifeStatus | Integer | 来客授权状态：0-未授权, 1-已授权, 2-授权过期, 3-授权失败, 4-授权中, 5-授权抖音号不匹配 |
| data.authLifeStatusTime | String | 来客授权状态修改时间（yyyy-MM-dd HH:mm:ss） |

## 请求示例

```
GET /replay/words/anchorUrl/getAuthStatus?secUid=2200756289440511
```

## 返回值示例

### 成功

```json
{
  "code": 0,
  "msg": "操作成功",
  "data": {
    "anchorUrlSecUid": "2200756289440511",
    "authJlbyStatus": 1,
    "authJlbyStatusTime": "2026-06-15 10:30:00",
    "authQcStatus": 2,
    "authQcStatusTime": "2026-07-10 14:22:00",
    "authChannelStatus": 0,
    "authLifeStatus": 0,
    "authLifeStatusTime": null
  }
}
```

### 记录不存在

```json
{
  "code": 30000,
  "msg": "记录不存在",
  "data": null
}
```

## 备注

- 接口基于当前登录用户的 `userId + tenantId` 做数据隔离，仅返回当前用户自己添加的主播
- 时间字段格式为 `yyyy-MM-dd HH:mm:ss`，未修改过时为 `null`
- 当 `secUid` 对应的主播未被当前用户添加时，返回 `code=30000`
