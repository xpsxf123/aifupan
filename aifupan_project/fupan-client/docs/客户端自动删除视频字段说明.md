# 客户端自动删除视频字段说明

「自动删除本地录制源视频」功能新增两个配置字段：

| 字段 | 含义 | 类型 |
|---|---|---|
| `autoDeleteTime` | 自动删除时间 | `String` |
| `deleteContent` | 删除内容（删源视频 / 删 mp4 成品 / 都删） | `String` |

---

## 一、加在哪两个接口

### 1.1 主播添加/修改接口

客户端提交/修改主播走两层接口，字段 `autoDeleteTime` / `deleteContent`（camelCase）从 Web 前端一路透传到服务端：

| 层 | 接口 | 入参 | 出参 |
|---|---|---|---|
| 客户端本地 HttpServer（Web 前端调用） | `POST api/anchorinfo/addOrUpdateAnchor`（`AnchorInfoController`） | `AddOrUpdateAnchorBo`（客户端） | `void`（本地 HttpServer 统一封装为 `HttpReponse`） |
| 客户端转发 fupan-server | `POST {BaseUrl}/anchorurl/addOrUpdateAnchor`（`AnchorApi.AddOrUpdateAnchor`） | `AddOrUpdateAnchorBo`（服务端） | `R<String>`，成功时 `data="添加成功"` |

返回值示例：

客户端本地 HttpServer（`api/anchorinfo/addOrUpdateAnchor`，方法返回 `void`）：

```json
{ "code": 0, "msg": "成功", "data": null }
```

fupan-server（`anchorurl/addOrUpdateAnchor`）：

```json
{ "code": 0, "msg": "", "data": "添加成功" }
```

> 客户端本地 HttpServer 所有接口（含 `void` 方法）统一封装为 `HttpReponse`：`code`=0 成功、非 0 失败；`msg` 成功时为 `"成功"`；`data` 为业务返回（`void` 时为 `null`）。fupan-server 统一返回 `R<T>`：`code`=0 成功、`msg` 成功时为空串、`data` 为业务对象。

存储：`tb_anchor_url_user` 表新增列 `auto_delete_time` / `delete_content`（`sql/replay-44.sql`）。

### 1.2 客户端本地配置接口（ReviewAnalysis 本地 HttpServer）

| 接口 | 方法 | 路径 | 出参 | 说明 |
|---|---|---|---|---|
| 查询配置 | GET | `api/config/getmodel` | `Config` | 返回 `Config`，含 `autoDeleteTime` / `deleteContent`（小写） |
| 修改配置 | POST | `api/config/updatemodel` | `void` | 更新 `Config`，含这两个字段 |

返回值示例（均为 `HttpReponse` 统一封装，`data` 承载业务对象）：

查询配置 `GET api/config/getmodel`（`data` 为 `Config`，仅展示与本功能相关字段）：

```json
{
  "code": 0,
  "msg": "成功",
  "data": {
    "Id": 1,
    ...原来字段
    "SavePath": "...",
    "autoDeleteTime": "-1",
    "deleteContent": "all"
  }
}
```

> `Config` 其余字段（`Id`/`SerialNumber`/`DetectionFre`/`SavePath`/`LimitType` 等）为 PascalCase；`autoDeleteTime` / `deleteContent` 为小写（与 JSON 序列化一致）。

修改配置 `POST api/config/updatemodel`（`Update` 方法返回 `void`）：

```json
{ "code": 0, "msg": "成功", "data": null }
```

> 全局配置存客户端本地 `Config/systemConfig.txt`，走客户端本地 HttpServer（`api/config` 前缀），不经过 fupan-server。

---

## 二、取值从哪里获取

两个字段的取值都来自**数据字典**（fupan-server「字典管理」后台维护，`sql/replay-44.sql` 注释已标注）：

| 字典类型 key（`tb_dict_type.logo`） | 名称 | 数据项（`tb_dict_data`：label=value） |
|---|---|---|
| `auto_delete_time` | 自动删除时间 | `不删除=-1`、`马上删除=0`、`1天后删除=1`、`3天后删除=3`、`7天后删除=7`、`30天后删除=30`、`90天后删除=90` |
| `delete_content` | 删除内容 | `删除源视频=ts`、`删除mp4视频=mp4`、`全部删除=all` |

### 获取字典的服务器接口

字典项由 fupan-server 提供，前端/客户端通过以下接口按 `logo` 拉取（返回启用态列表）：

| 项 | 内容 |
|---|---|
| 方法 | `GET` |
| 路径 | `/replay/system/dictData/dictDataListByCode` |
| 入参 | `code`（String，必填）= 字典类型标识（`tb_dict_type.logo`） |
| 出参 | `R<List<DictDataListVo>>`，每个 `DictDataListVo` 含 `label`（显示名）/ `value`（存储值） |

调用示例：

| `code` 取值 | 返回的 label=value 数据项 |
|---|---|
| `auto_delete_time` | `不删除=-1`、`马上删除=0`、`1天后删除=1`、`3天后删除=3`、`7天后删除=7`、`30天后删除=30`、`90天后删除=90` |
| `delete_content` | `删除源视频=ts`、`删除mp4视频=mp4`、`全部删除=all` |

返回值示例（`GET /replay/system/dictData/dictDataListByCode?code=delete_content`）：

```json
{
  "code": 0,
  "msg": "",
  "data": [
    { "id": 1, "typeId": 2, "label": "删除源视频", "value": "ts", "status": 0, "sort": 1, "parentId": null, "createDate": "2026-08-01 10:00:00", "updateDate": "2026-08-01 10:00:00", "isDeleted": 0, "typeName": "删除内容", "children": null },
    { "id": 2, "typeId": 2, "label": "删除mp4视频", "value": "mp4", "status": 0, "sort": 2, "parentId": null, "createDate": "2026-08-01 10:00:00", "updateDate": "2026-08-01 10:00:00", "isDeleted": 0, "typeName": "删除内容", "children": null },
    { "id": 3, "typeId": 2, "label": "全部删除", "value": "all", "status": 0, "sort": 3, "parentId": null, "createDate": "2026-08-01 10:00:00", "updateDate": "2026-08-01 10:00:00", "isDeleted": 0, "typeName": "删除内容", "children": null }
  ]
}
```

> 关键字段：`data[].label` 为显示名、`data[].value` 为存储值（即 `autoDeleteTime` / `deleteContent` 的取值）；`code=0` 表示成功。其余 `id/typeId/sort/parentId/status/isDeleted/createDate/updateDate` 为字典通用字段，本功能不关心（`createDate/updateDate` 时间格式以服务端实际序列化为准，此处仅为示意）。

### 取值语义速查

| 值 | `autoDeleteTime` 含义 | `deleteContent` 含义 |
|---|---|---|
| `-1` | 不删除 | — |
| `0` | 马上删除 | — |
| `N`（正整数） | 超过 N 天后删除 | — |
| `ts` / `mp4` / `all` | — | 删源视频 / 删 mp4 成品 / 两者都删 |
| 空 / null | 跟随全局 | 跟随全局 |

> `deleteContent` 区分「删源视频」还是「删 mp4 成品」还是「都删」，不再区分源视频格式（ts/flv）。
> mp4 成品路径由 `storage_path` 对应的视频转出（`AnalysisUtils.getVideoMp4Path` 计算），不在 `storage_path` 内。
