# 视频详情页商品分页查询

> **所属服务：企业后台（fupan-governance-server）**

## 接口信息

| 项目 | 内容 |
|---|---|
| 路径 | `/api/governance/performance/video/productPage` |
| 方法 | `POST` |
| Content-Type | `application/json` |
| 鉴权 | 需登录（Bearer Token） |

## 请求参数（JSON Body）

| 参数 | 类型 | 必填 | 说明 |
|---|---|---|---|
| batchNumber | String | 是 | 直播批次号 |
| videoId | String | 否 | 爱复盘视频ID。传入后从视频表获取真实 tenantId，不受当前用户租户限制 |
| startTime | String | 否 | 视频开始时间（格式：yyyy-MM-dd HH:mm:ss） |
| endTime | String | 否 | 视频结束时间（格式：yyyy-MM-dd HH:mm:ss） |
| page | Integer | 否 | 页码，从 1 开始，默认 1 |
| limit | Integer | 否 | 每页条数，默认 10 |
| sortBy | String | 否 | 排序字段，默认 payAmt（成交金额）。可选值见下方备注 |
| sortOrder | String | 否 | 排序方向：asc-升序、desc-降序，默认 desc |

## 返回字段说明

| 字段 | 类型 | 说明 |
|---|---|---|
| code | Integer | 状态码，0=成功 |
| msg | String | 提示信息 |
| data | Object | 分页数据对象 |
| data.pullStatus | Boolean | 是否已拉取商品数据。false 表示该直播场次尚未拉取数据，此时 records 为空 |
| data.total | Long | 总条数 |
| data.pageNum | Integer | 当前页码 |
| data.pageSize | Integer | 每页条数 |
| data.pages | Long | 总页数 |
| data.records | Array\<ProductItem\> | 商品列表 |

### ProductItem 字段

| 字段 | 类型 | 说明 |
|---|---|---|
| title | String | 商品标题 |
| imageUri | String | 商品封面图 |
| productShowViewRatio | BigDecimal | 曝光观看率 |
| productShowUcnt | Long | 曝光人数 |
| productViewShowRatio | BigDecimal | 观看商品曝光率 |
| productClickUcnt | Long | 点击人数 |
| productShowClickUcntRatio | BigDecimal | 曝光点击率 |
| productClickPayUcntRatio | BigDecimal | 点击成交转化率 |
| avgPayAmtPerOrder | BigDecimal | 成交单价 |
| payCnt | Long | 订单量 |
| payAmt | BigDecimal | 成交金额 |

## 请求示例


## 备注

- **videoId 参数**：传入时接口从爱复盘视频表获取真实 `tenantId`，不再使用当前登录用户租户。不传则沿用当前用户租户
- 接口先查 `live_video` 表判断该租户 + 批次号是否已拉取过数据，未拉取时直接返回 `pullStatus=false`、空商品列表
- 当 `video_product.product_oss_key` 有值时，后续会根据 `startTime~endTime` 解析 OSS 商品过程数据计算时间段内指标（TODO，拉取流程完成后再实现）
- 时间字段格式为 `yyyy-MM-dd HH:mm:ss`
- **排序**：仅支持单字段排序，`sortBy` 可选值（9 个指标字段）：
  `productShowViewRatio`、`productShowUcnt`、`productViewShowRatio`、`productClickUcnt`、`productShowClickUcntRatio`、`productClickPayUcntRatio`、`avgPayAmtPerOrder`、`payCnt`、`payAmt`
- 不传或传入非法排序字段时，默认按**成交金额（payAmt）降序**排列
