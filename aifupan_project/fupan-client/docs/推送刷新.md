# 视频分析进度通知 — 前端对接文档

## 概述

C# 客户端在执行视频分析（`lockanalysis` 接口）时，通过 `NoticeJs` 实时推送进度到内嵌前端。前端监听 `videoAnalysisProgress` 事件即可获取进度。

## 通信方式

C# 端通过 `FrontNotice.NoticeJs(jsonString)` 推送 JSON 字符串到 CefSharp 内嵌浏览器，前端在 `window` 上接收。

## 事件名

`videoAnalysisProgress`

## 触发时机

| 阶段 | `progressStatus` | 说明 |
|---|---|---|
| 开始分析 | `started` | `lockanalysis` 接口被调用，分析流程开始 |
| 视频下载完成 | `downloadDone` | 从服务端下载分析结果 ZIP 文件成功 |
| 分析完成 | `completed` | 全部 13 个步骤执行完毕，即将返回数据 |
| 分析失败 | `failed` | 任意步骤抛出异常，`msg` 携带错误原因 |

## 数据结构

所有通知统一 `code: 0, status: 200`（通知本身发送成功）。

### 开始分析

```json
{
  "code": 0,
  "status": 200,
  "action": "videoAnalysisProgress",
  "data": {
    "videoId": "7123456789012345678",
    "progressStatus": "started"
  }
}
```

### 视频下载完成

```json
{
  "code": 0,
  "status": 200,
  "action": "videoAnalysisProgress",
  "data": {
    "videoId": "7123456789012345678",
    "progressStatus": "downloadDone"
  }
}
```

### 分析完成

```json
{
  "code": 0,
  "status": 200,
  "action": "videoAnalysisProgress",
  "data": {
    "videoId": "7123456789012345678",
    "progressStatus": "completed"
  }
}
```

### 分析失败

```json
{
  "code": 0,
  "status": 200,
  "action": "videoAnalysisProgress",
  "data": {
    "videoId": "7123456789012345678",
    "progressStatus": "failed",
    "msg": "Unable to connect to the remote server"
  }
}
```

## 字段说明

| 字段 | 类型 | 说明 |
|---|---|---|
| `code` | int | 固定 0，表示通知发送成功 |
| `status` | int | 固定 200 |
| `action` | string | 固定 `videoAnalysisProgress` |
| `data.videoId` | string | 当前分析的视频 ID |
| `data.progressStatus` | string | `started` / `downloadDone` / `completed` / `failed` |
| `data.msg` | string | 仅 `failed` 时有值，异常错误信息 |

## 注意事项

1. `failed` 不会阻止方法继续执行——catch 块内记录日志后返回空的 `sentenceMarkDto`
2. `started` 在 `try` 块入口立刻发送，不依赖任何异步操作
3. `downloadDone` 仅在有本地缓存未命中、需要从服务端下载时才发送。如果本地已有分析文件，不会触发此状态
4. 所有通知均为"尽力而为"，不保证送达顺序（但正常流程下 `started → downloadDone → completed` 顺序不会乱）
