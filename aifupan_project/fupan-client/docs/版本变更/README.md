# 版本变更记录

## 目录结构

- `docs/版本变更/<版本号>.md`
  - 示例：`docs/版本变更/2.6.0.8.md`

## 自动写入规则（仓库内）

- 变更来源：仅从 `test-xxx` 和 `reslease-xxx` 分支的代码变更中提取，不再从 `dev-xxx` 分支提取。
- 提交时会自动读取当前 Git 分支名中的版本号（忽略 `test/reslease` 等前缀，只提取版本号数字段）
- 若本次提交包含功能新增/修改（通常表现为 `src/` 等代码文件有变更），会自动将本次变更写入当前版本号对应的变更记录文件
- 若版本号与分支不一致，会阻止提交并清理本次对版本文档的修改
- 版本变更文件末尾需包含「版本功能明细」表格，列出当前版本完整功能清单供测试验收使用

## 记录格式（简洁版）

文件采用“目录 + 表格”结构，便于索引与检索。

表格每行固定字段：

- 记录时间
- 功能变更标题
- 功能变更模块
- 功能变更文件
- 功能变更详细内容（简洁）
