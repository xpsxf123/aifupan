# Self Skills Index (project/business)

This directory stores project/business-bound skills for this agent. Do not put reusable skills here.

- Convention: self_skills/<skill_name>/SKILLS.md + self_skills/<skill_name>/templates/

## Project Skills (fupan-client)

- project_component_catalog: 项目组件资源索引与选型（从清单到技能入口）
- core_table_page_builder: 基于 CoreTable 的列表页骨架（搜索/表格/分页/操作）
- table_column_render_recipe: Table/Column 列配置与渲染规范（formatter vs option.render）
- dialog_drawer_recipe: Dialog/Drawer 的统一弹窗与抽屉使用规范
- ai_content_rendering_pipeline: AI 内容统一渲染入口与 mdTag 渲染约定
- branch_version_tracker: 分支版本追踪，自动维护版本开发目录与版本变更文件，包含重复分支冲突检测与版本功能明细维护
