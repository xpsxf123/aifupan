# 组件选型检查单

## 页面类型

- [ ] 列表页（搜索/分页/操作列）
- [ ] 详情页（信息分组/卡片/步骤）
- [ ] 配置页（表单为主）
- [ ] 分析页（图表/AI/对比/切片）
- [ ] 弹窗/抽屉（功能块承载）
- [ ] 分享页（独立路由容器）

## 优先复用路径

- [ ] 先查 `src/components`（通用基础组件）
- [ ] 再查 `src/views/commonComponent`（页面级通用功能块）
- [ ] 再查 `src/views/modules/<module>/component`（模块内复用组件）

## 列表页（如命中）

- [ ] 可用 CoreTable 覆盖（搜索 + 表格 + 分页 + 批量）→ 优先 CoreTable
- [ ] 列渲染：简单文本用 formatter；复杂结构用 option.render

## 弹窗/抽屉（如命中）

- [ ] 标准弹窗用 Dialog（内置滚动）
- [ ] 侧滑用 Drawer（支持 ref 命令式 show/hide）

## AI/分析（如命中）

- [ ] AI 内容渲染统一走 aiContent 与渲染管线
- [ ] 图表先复用 analysis/compass 与 curveData 等既有组件

## 输出要求（用于落地）

- [ ] 明确组件清单（路径 + 关键 props/slots/events）
- [ ] 明确数据流（接口/状态/路由参数）
- [ ] 明确放置位置（src/components vs commonComponent vs module/component）
