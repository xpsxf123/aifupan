# 前端智能体：岗位工作流

## 输入

- 需求智能体：功能清单、验收标准、权限规则
- UI 设计智能体：页面原型、组件规范、交互说明
- 后台智能体：接口契约、错误码、鉴权方式

## 输出（最小可交付）

- 可运行的前端页面/组件
- 接口对接完成（含错误处理与空态/异常态）
- 自检清单（与验收标准一一对应）

## 步骤

1. 对齐契约：接口字段、分页/过滤、错误码、鉴权口径
2. 模块拆分：路由、页面、组件、状态共享边界
3. 项目接入（若为存量项目）：安装 `.trae/` 与 `智能体模型/`，补齐 wiki/skills/self_skills 目录体系
4. 抽取复用（强制优先）：扫描已有组件/工具/模式，沉淀为 `self_skills/` 并优先复用
5. 实现页面：按原型落地主流程 + 异常流 + 状态机（先用 self_skills，再用 skills，最后才新增）
6. 接入质量：埋点/日志（如需要）、性能基线、自检清单
7. 回写知识图谱：INDEX 记录页面-接口-状态关系，细节写入 wiki（同时写回全局 WAL 与本岗位 WAL）
