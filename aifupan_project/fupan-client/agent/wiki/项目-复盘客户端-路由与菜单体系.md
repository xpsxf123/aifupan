# 项目-复盘客户端-路由与菜单体系

## 本文档用途

- 统一解释：哪些路由是静态定义，哪些路由由菜单动态挂载，以及页面组件路径是如何从 menu.json 解析出来的。
- 给“新增一个页面/菜单”提供可复用的落点与检查清单。

## 定义

本项目路由由两部分组成：

- 静态路由：直接写在 `src/router/index.js` 的 `pageRoutes`
- 动态路由：启动时读取 `src/assets/json/menu.json`，根据菜单配置批量生成路由并挂载到主 Layout 下

## 静态路由（pageRoutes）

静态路由主要覆盖：

- 登录与版本选择页
- 分享/在线分析相关页（shareLayout/aiShareLayout 容器）
- 404、屏保、周年庆等少量独立入口

落点：`src/router/index.js`

## 动态路由（menu.json）

### menu.json 的角色

`src/assets/json/menu.json` 同时承担两件事：

- 左侧菜单数据源
- 动态路由配置源

### 字段结构（高频字段）

- `path`：路由路径
  - 顶层常见绝对路径：`/dataAnalysis`
  - 子路由常见相对路径：`hotList`（最终拼接为 `/dataAnalysis/hotList`）
  - 也存在通配写法：`*/analysis`
- `name`：路由名
  - Web 环境白名单放行是按 `name` 判断
- `filePath`：页面组件路径定位
- `meta`：页面元信息
  - `title`：页面标题（也用于 document.title）
  - `notKeepAlive`、`notTabs`、`returnPath/returnTitle`、`hideTabs` 等
- `children`：子路由数组
- `notLayout`：为 true 时，不挂在 Layout children 下，而是直接 addRoute

## 组件路径解析规则（menu → views 组件）

动态路由会把 `filePath`（或缺省使用 `path`）解析成最终组件 import 路径，核心规则：

- 以 `/` 开头：以 `@/views` 为根
  - 例：`/layout` → `@/views/layout/index.vue`
- 不以 `/` 开头：以 `@/views/modules` 为根
  - 例：`dataAnalysis/index` → `@/views/modules/dataAnalysis/index.vue`
- 若未写 `.vue`：
  - 默认补全为 `.../index.vue`
  - 若末段就是 `index`，直接补 `.vue`
- 解析后会做路径存在性校验，不存在则跳过该菜单项

落点：`src/router/index.js` 内 `getComponent()` / `getComponentUrl()`。

## 动态路由生成规则（children 的处理）

当菜单项存在 `children` 时，会生成一个“二级容器路由”：

- `component` 固定为 `@/views/layout/routerView.vue`（只提供 `<router-view/>`）
- `children` 会额外插入一个默认子路由 `path:'/'`
  - 用于“访问父路径时渲染父页面组件”

## Layout 包裹规则

多数业务页面路由会被收集到 `LayoutComponent.children`，最终统一 `addRoute('main', LayoutComponent)`。

例外：

- `notLayout:true` 的路由会直接 `router.addRoute('main', routeObj)`

## permission.js（放行/拦截/标题）

落点：`src/router/permission.js`

- dev 环境：直接放行
- Web 环境：仅允许 `webUrlList`（按路由 name 白名单）访问，否则跳 `/404`
- afterEach：标题取最近 matched 且有 `meta.title` 的值

项目内已整理“页面名称 ↔ URL”的表格文档：

## 新增页面/菜单（最小步骤）

- 在 `src/views/modules/<module>/` 下创建页面（通常以 `index.vue` 为入口）
- 在 `src/assets/json/menu.json` 新增菜单项：
  - `path/name/filePath/meta.title`
  - 若为父子结构，补齐 children，并确认子 path 是否为相对路径
- 自检：
  - 路由可解析到真实文件（否则会被跳过）
  - Web 环境是否需要加入 `webUrlList`
  - title 是否正确
