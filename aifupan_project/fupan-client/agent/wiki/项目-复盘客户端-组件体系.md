# 项目-复盘客户端-组件体系

## 本文档用途

- 统一解释：组件分层、组件目录边界、如何复用以及如何把业务功能块沉淀为组件。
- 给后续“按页面搭建组件树”提供可复用的组件选型入口。

## 组件分层（按复用边界）

### 1) 全局通用组件（src/components）

特点：

- 跨模块复用
- 多为“基础能力组件”或“通用业务组件”

典型能力：

- 表格：CoreTable / Table / Column / Operation
- 搜索：Search
- 表单控件：Input/Select/DatePicker/Radio/RadioGroup
- 弹窗/抽屉：Dialog/Drawer/GlobalConfirm
- AI/分析域组件：aiContent 渲染、分析图表、标注、滚动弹幕等

### 2) 页面级通用组件（src/views/commonComponent）

特点：

- 跨模块复用，但粒度更大（通常包含多个基础组件组合）
- 偏“页面功能块”与“复杂交互容器”

典型：

- analysisLayout（分析布局/对比/只读）
- onlineAnalysisDialog、sliceAnalysis、videoMark/keywordMark 等

### 3) 模块内组件（src/views/modules/**/component）

特点：

- 仅在某个模块/子域内复用
- 粒度介于“基础组件”与“页面功能块”之间

注意：

- 项目实际目录名为 `component`（非 `components`），新增组件时建议沿用现状，避免目录分裂。

## 组件复用原则（建议）

- 优先复用 `src/components` 的基础能力组件组合页面
- 模块内重复出现的弹窗/表单/表格，优先抽到 `src/views/modules/<module>/component`
- 跨模块复用且具有稳定性价值的，升级到 `src/views/commonComponent` 或 `src/components`

## 高价值通用组件（建议优先沉淀为技能）

### CoreTable（搜索 + 表格 + 分页一体）

适用：

- 列表页（带搜索/分页/操作列/批量选择/导出等）

关键点：

- 既支持 `getDataApi` 拉取数据，也支持 `tableList` 静态数据
- `column` 复用 Table/Column 体系（支持 slot、formatter、option.render）
- 具备内置 buffer 缓存与接口生命周期事件

### Table/Column（列渲染约定）

建议约定：

- 简单文本格式化走 `formatter(row)`
- 复杂结构走 `option.render(row)` 返回 HTML 字符串（Column 内 v-html）
- 交互事件走 `option.on`

### Search（配置驱动的搜索表单）

关键点：

- `searchConfig.items[]` 描述字段与控件类型（temp）
- `on.change/on.input` 可以直接触发 search 或执行回调

### Dialog/Drawer（统一弹窗/抽屉）

关键点：

- Dialog 内置滚动容器
- Drawer 支持 ref 命令式 show/hide

### AI 内容渲染（analysis/ai/common）

关键点：

- 公共入口：`src/components/aiContentRenderer/`
  - 组件：`aiContentRenderer/index.vue`
  - 分发：`aiContentRenderer/renderers/aiContentRenderParser.js`
- 兼容入口：`src/components/analysis/ai/common/*RenderParser.js` 仍可用（内部转发到公共实现，确保现有 AI 对话渲染不受影响）
- mdTag 走“占位 → Markdown 转 HTML → 回填”流程，并带二次清洗与内置图表渲染；pureMd 会清除 aifupan 自定义标签，仅保留 Markdown 渲染
