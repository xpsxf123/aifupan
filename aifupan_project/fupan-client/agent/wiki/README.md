# wiki（内容层）

## 写作约定

- 一页一个概念：`wiki/<概念名>.md`
- 必须包含：定义、适用范围、示例、相关链接（指向 INDEX 中的实体）
- 大段细节放 wiki，不放 INDEX
- 推荐按域组织：优先通过 `wiki/KNOWLEDGE_GRAPH.md` 与各域 `index.md` 导航

## 推荐页面类型

- 岗位工作流：从输入到交付的分步流程
- 模板：可复用的产出结构（文档/代码/检查清单）
- 常见错误：容易踩坑的点与修正方式
