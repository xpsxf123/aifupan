# 项目-复盘客户端-架构概览

## 本文档用途

- 给新加入成员/智能体一个“从零理解项目”的统一入口：项目是什么、入口在哪里、模块如何划分、核心数据流如何走。
- 作为知识图谱的总览节点，关联路由/组件/请求/状态/推送等专题文档。

## 定义

“复盘客户端”是一个基于 Vue 2 + Element-UI 的前端项目，面向两种运行形态：

- 客户端形态：通过本地 `clientApiURL`（默认 `http://127.0.0.1:<port>/api`）与桌面端（C#）或本地服务交互，并通过 `$CSharpNotify` 接收 C# 推送事件。
- Web 形态：通过 `BUILD_TARGET=website` 构建为网站入口；部分“仅客户端可用能力”会在 Web 环境被限制或直接拒绝调用（例如 `request-client` 在 `env.isWeb` 下直接 reject）。

## 技术栈

- Vue 2（vue-router、vuex）
- Element-UI（表单、表格、弹窗、Popover、Tooltip 等）
- axios（两套请求封装：back/client，并提供 back2 的 baseURL 注入扩展）
- ECharts（分析图表）
- Markdown/AI 渲染（AI 内容渲染管线：mdTag 占位 → Markdown 转 HTML → 回填）

## 关键入口

- 应用入口：`src/main.js`
  - 全局注入：`$httpBack`、`$httpClient`、`$httpBack2/$httmlBack2`、`$CSharpNotify` 等
  - 启动链路：`initApp()` → `new Vue({ router, store })`
- 路由入口：`src/router/index.js`
  - 静态路由 + `menu.json` 动态路由挂载（详见《项目-复盘客户端-路由与菜单体系》）
- 权限/放行：`src/router/permission.js`
  - Web 环境路由白名单、标题设置、资源页特殊处理
- 配置入口：
  - `vue.config.js`：构建入口、RUN_ENV/BUILD_TARGET、模板注入变量、版本信息
  - `ipConfig/index.js`：各环境 back/client API URL、签名配置、平台 code
- 状态入口：`src/store/index.js`
  - 持久化 key：`replayVuex`，并限制持久化字段

## 目录与模块边界（建议理解方式）

- `src/views/pages/*`：独立页面（登录、分享、官方页等，通常是静态路由承载）
- `src/views/layout/*`：主布局（左侧菜单、顶部标题、路由容器等）
- `src/views/modules/*`：核心业务模块（通过 `menu.json` 动态路由承载）
- `src/views/commonComponent/*`：跨模块复用的“页面级组件/复杂功能块”（偏业务通用）
- `src/components/*`：全局通用组件库（表格、搜索、弹窗、表单控件、AI/分析域组件等）
- `src/utils/*`：工具与基础能力（请求、签名、推送桥、格式化、下载、拖拽等）

## 核心数据流（从 UI 到后端/客户端）

- 页面/组件
  - 读取路由参数（`$route.params/$route.query`）与 store（`mapState/mapGetters`）
  - 调用 API：`this.$httpBack / this.$httpClient / this.$httmlBack2`
  - 接收推送：`this.$CSharpNotify.addTask(action, handler)`
- 请求层（axios 封装）
  - back：带 Token/source/签名、loading、格式化、4001 跳登录等
  - client：根据 UA 解析端口覆盖 baseURL、Web 环境禁用、部分 code 特判
- store（Vuex）
  - 持久化关键字段；部分接口在 API 聚合层内部直接 commit
