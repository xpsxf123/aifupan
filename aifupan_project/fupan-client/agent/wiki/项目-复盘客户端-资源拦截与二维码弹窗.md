# 项目-复盘客户端-资源拦截与二维码弹窗

## 定义

“资源拦截与二维码弹窗”用于统一处理以下场景：

- 用户操作前需要做资源/权限判定（例如：授权数量不足、算力不足、版本不支持）
- 判定失败时弹出“客服二维码”并展示对应的引导文案
- 判定通过时继续执行原操作，并向外提供成功回调

## 适用范围

- 列表行操作按钮（生成报告/开启监控/开启巡检等）
- 表单中的开关/复选框（勾选时需要判定资源）
- 任意需要“先判定再执行”的交互

## 组件与数据

- 类型枚举：`src/enum/qrCodeDialogEnum.js`
  - `QR_CODE_DIALOG_TYPE`：弹窗类型
  - `QR_CODE_DIALOG_LABEL`：类型 label（可用于埋点/日志/展示）
- 文案配置：`src/components/qrCodeGuard/dialogCopywriting.json`
  - key 为 `QR_CODE_DIALOG_TYPE` 值
  - value 为可渲染的 HTML 文案（通过 `v-html` 渲染）
- 二次封装弹窗组件：`src/components/qrCodeGuard/QrCodeDialog/index.vue`
  - 企业版以下：展示默认“激活/免费版升级提示”
  - 企业版及以上：按 `type` 渲染 JSON 中的文案（也可传入 `html` 直接覆盖）
  - 二维码获取逻辑复用 `customerServiceQrCode` 内部实现
- 资源拦截动作组件：`src/components/qrCodeGuard/GuardAction/index.vue`
  - 支持默认按钮渲染，也支持 slot 自定义（复选框/自定义按钮等）
  - 支持外部通过 hook 自定义判定逻辑

## 资源判定约定（Hook）

`GuardAction` 接收 `check`（函数）作为资源判定 hook：

- hook 返回 `false / undefined / null`：表示资源充足 → 放行 → 触发 `success`
- hook 返回 `type`（字符串）：表示资源不足 → 弹出对应类型二维码弹窗
- hook 返回 `{ type, html }`：弹出二维码弹窗，并使用 `html` 覆盖默认文案

## 示例

### 按钮拦截

- 通过：`check` 返回 `false`，触发 `success`
- 拦截：`check` 返回对应 `type`，弹出二维码弹窗

### 复选框拦截

通过 slot 取到 `guard`，在 checkbox 的 `change` 时调用：
