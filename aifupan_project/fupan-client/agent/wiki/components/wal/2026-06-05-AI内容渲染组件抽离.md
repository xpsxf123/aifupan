# WAL - 组件沉淀片段

## 变更摘要
- 抽离 AI 内容渲染能力为公共组件 `src/components/aiContentRenderer/`，并把渲染实现（json/mdTag/pureMd）统一收拢到 `aiContentRenderer/renderers/`。
- 保留历史入口 `src/components/analysis/ai/common/*RenderParser.js` 作为兼容转发，确保现有 AI 对话/报告渲染结果不受影响。
- 将提示词渲染相关的规范文档迁移到 `src/components/aiContentRenderer/prompt-doc/`。

## 组件信息
- 名称：AiContentRenderer
- 归属模块：AI（公共渲染基础能力）
- 复用边界（跨模块/模块内/仅页面内）：跨模块（可用于任意需要渲染 AI 输出的页面/弹窗/详情/导出）

## API
- props：
  - content: String（需要渲染的 AI 内容）
  - thinkingContent: String（可选，深度思考内容）
  - renderMode: String（默认 mdTag；可选 pureMd/mdTag/json）
  - plainTextMode: Boolean（纯文本模式时强制走 pureMd）
  - option: Object（透传渲染 option）
  - enableLinkOpen: Boolean（默认 true；开启后点击 A 标签会新开页）
- emits：无
- slots：无

## 使用示例
```vue
<AiContentRenderer
  :content="answer"
  :thinkingContent="thinking"
  renderMode="mdTag"
/>
```

## 影响范围
- 新增公共渲染入口供全局复用；原有 AI 渲染链路无需改动即可继续工作（通过兼容转发保持稳定）。

## 证据
- 文件/代码入口：
  - src/components/aiContentRenderer/index.vue
  - src/components/aiContentRenderer/renderers/*
  - src/components/analysis/ai/common/aiContentRenderParser.js（兼容转发）
