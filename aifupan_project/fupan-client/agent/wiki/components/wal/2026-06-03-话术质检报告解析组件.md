# WAL - 组件沉淀片段

## 变更摘要
- 新增“话术质检报告解析组件”，兼容 reportContent 返回 HTML / JSON / Markdown(JSON) 三种形态，统一渲染为可读的报告视图，并在报告弹窗与详情页接入。

## 组件信息
- 名称：ScriptQualityReportContent
- 归属模块：AI 监控（话术质检）
- 复用边界（跨模块/模块内/仅页面内）：跨模块（弹窗 reportDialog 与详情页 DiscernSearchContainer 共用）

## API
- props：
  - report: Object（可选，完整报告对象，优先读取 report.reportContent/report.summaryJson）
  - content: String|Array|Object（可选，原始 reportContent）
  - summaryJson: String（可选，顶层 summaryJson 兜底）
- emits：无
- slots：无

## 样式与主题
- scss 变量/依赖：无
- 公共样式引用：组件自带 scss

## 使用示例
- 报告弹窗：`<ScriptQualityReportContent :report="reportData" />`
- 详情页内容区：`<ScriptQualityReportContent :content="scriptQualityContents" />`

## 影响范围
- 话术质检报告弹窗展示方式由“v-html 直出”改为“解析后结构化渲染”
- 详情页“话术质检”tab 展示方式由“逐段 v-html”改为“解析后结构化渲染”
