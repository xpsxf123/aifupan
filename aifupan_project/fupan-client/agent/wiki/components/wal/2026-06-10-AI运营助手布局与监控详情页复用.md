# 音频联动（不显示画面但可播放）

## 事件契约（推荐复用）

- 文本侧触发跳播：
  - `wordDiscern` / `DiscernSearchContainer` 在点击段落/拖动定位条时，会 `$emit('playerReadied', second, 'click')`
- 外层接管播放：
  - 父容器调用 `contrastVideo.ponlayerReadied(second, type)` 来设置 `currentTime` 并 `play()`
- 播放进度反哺文本高亮：
  - `contrastVideo @playerTimeupdate` 回调到外层，再调用 `wordDiscern.setVideoCurrentTime(time)` 同步高亮/定位

## 关键组件

- 视频播放器（支持不改内部实现的“仅声音播放”）：[contrast-video.vue](file:///c:/Users/JYJY/Desktop/fupan-client/src/views/commonComponent/analysisLayout/contrast-video.vue)
- 文本同步：`wordDiscern.setVideoCurrentTime(time)`（秒 → 内部转毫秒，并同步 sliderValue）

# 新增页面：AI监控详情（左原文 + 右报告，可收起）

- 路由：`/replayMonitorDetail`（menu.json 注册但不出现在左侧导航菜单）
- 页面入口：[monitorDetail/index.vue](file:///c:/Users/JYJY/Desktop/fupan-client/src/views/modules/replay/monitorDetail/index.vue)
- 布局实现：[MonitorDetailLayout.vue](file:///c:/Users/JYJY/Desktop/fupan-client/src/views/modules/replay/monitorDetail/components/MonitorDetailLayout.vue)

## 复用策略

- 左侧“原文/分钟段落”：复用 `wordDiscern`（保留搜索，关闭行业/导出等）
- 右侧“质检/巡检/还原度”：复用另一个 `wordDiscern`，通过外部 radio-button 驱动 `toActiveText()`，并设置 `notLocatingBar/notSearch/notExport/notTarde`
- 播放能力：复用 `contrastVideo`，CSS 移出可视区，仅承担音频播放与 timeupdate 回调
- 右侧收起：复用 `aiFold` 的交互与 icon，重写其定位样式以适配“两栏布局”

# 复用注意事项

- `DiscernSearchContainer.setTextType()` 对 `scriptQuality/interactionInspection/scriptRestoration` 的数据刷新依赖 `wordDiscern.changeTextType` 链路，单独使用 `DiscernSearchContainer` 容易出现“切换不触发报告状态刷新”的问题；推荐复用 `wordDiscern` 作为外层。
- 需要“从原详情页 tab 跳到新页并回到分钟段落”的场景，优先在 `contrast-only.tabsClick` 外层做跳转与复位，避免改动 `contrastVideo` 内部实现。
