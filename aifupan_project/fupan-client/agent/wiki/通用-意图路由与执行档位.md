# 通用-意图路由与执行档位

本页用于把用户请求按“执行档位”路由，避免同一套行为处理所有任务导致失控。

## 常用档位（推荐）
- Learn：解释/对齐概念/定位入口（不改代码）
- Patch：小范围增量修改（可回滚）
- Standard：多文件改动 + 验证 + 写回（默认）
- Governance：仅做 skills/wiki/INDEX/规则治理（不碰业务代码）

## 路由规则（简化版）
- 涉及目录/规则/技能体系变更 → Governance
- 明确 bug 修复且影响面小 → Patch
- 需求不清晰/需要先对齐接口契约 → Learn
- 其余默认 → Standard

## 输出要求（不同档位）
- Learn：给入口链接 + 关键约束 + 待确认项
- Patch：给改动点 + 关键文件 + 自检路径
- Standard：补齐 Focus Card / 任务拆解 / 验收清单 / 写回计划
- Governance：更新 skills/wiki/INDEX + CHANGE_LOG
