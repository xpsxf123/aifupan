# 主播授权状态查询接口与统一授权组件

## 接口信息

| 项目 | 内容 |
|---|---|
| 路径 | `GET /replay/words/anchorUrl/getAuthStatus` |
| 服务 | fupan-server（云端后台） |
| 鉴权 | 需登录（Bearer Token） |
| 参数 | `secUid`（Query，主播唯一标识） |
| 前端封装 | `src/utils/liveRoomAuthStatus.js` → `getLiveRoomAuthStatus(secUid)` |
| API 注册 | `src/utils/request-api-back.js` → `api.words.getAuthStatus` |
| 接口文档 | `docs/主播授权接口.md` |

## 返回状态字段

| 字段 | 说明 | 状态值 |
|---|---|---|
| `authJlbyStatus` | 巨量百应授权状态 | 0-未授权, 1-已授权, 2-过期, 3-失败, 4-授权中, 5-抖音号不匹配 |
| `authLifeStatus` | 来客授权状态 | 同上 |
| `authQcStatus` | 千川授权状态 | 同上 |
| `authChannelStatus` | 视频号授权状态 | 0-未授权, 1-已授权, 2-微信取消, 3-用户取消 |

## 统一授权组件

`src/components/liveRoomAuthorizeDialog.vue` 作为所有授权能力的统一入口：

### 两种模式
- **弹窗模式** (`mode="dialog"`)：radio 选择授权平台，适用于直播间列表的"点我授权"
- **按钮模式** (`mode="button"`)：内联按钮+状态标签，适用于添加成功弹窗等场景

### Props
- `mode`: `'dialog'` | `'button'`
- `layout`: `'horizontal'` | `'vertical'`（仅按钮模式）
- `platforms`: `['juliang', 'life', 'qianchuan']` 等平台 key 列表

### 平台能力配置
组件内置 `PLATFORM_CAPABILITIES` 集中管理各平台授权动作，新增平台只需在此注册即可。
