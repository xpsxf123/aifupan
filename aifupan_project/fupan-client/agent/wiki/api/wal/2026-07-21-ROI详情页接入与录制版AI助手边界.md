# 目标

沉淀 ROI 相关接口在“云空间详情页 / 录制版 / AI 助手”三类场景中的展示边界与接入点，后续同类需求优先复用本结论，避免误把 ROI 展示到文件详情、纯录制版或 AI 助手页面。

# 结论

## 1) ROI 展示边界

- 仅在云空间视频详情页展示：
  - `targetType === 'online'`
  - `targetType === 'webOnline'`
- 不展示的场景：
  - 文件详情 / 上传文件详情（无 `videoInfo.VideoId`）
  - 纯录制版（`versionType === VERSION_TYPE.PURE` 或 `store.getters.isPure`）
  - AI 助手页（`aiAnalysis-item.vue` 及其复用链路中的 `DiscernSearchContainer isAi=true`）

## 2) 录制版入口与判定链路

- 版本选择入口：[index.vue](file:///c:/Users/JYJY/Desktop/fupan-client/src/views/pages/versionSelection/index.vue)
  - 通过 `this.$httpClient.setup.setClientVersionConfig({ clientVersion })` 持久化客户端版本
  - 选择“纯录制版”时写入 `clientVersion: 'record'`
  - 选择“AI全能版”时写入 `clientVersion: 'replay'`
- 状态落点：[store/index.js](file:///c:/Users/JYJY/Desktop/fupan-client/src/store/index.js)
  - `getVersionType` 负责把客户端版本映射到 `VERSION_TYPE`
  - `isPure` 用于按套餐值兜底判断纯录制版
- 复盘详情中的常见纯录制版屏蔽点：
  - [controlTabs.vue](file:///c:/Users/JYJY/Desktop/fupan-client/src/components/analysis/controlTabs.vue)
  - [DiscernSearchContainer/index.vue](file:///c:/Users/JYJY/Desktop/fupan-client/src/components/DiscernSearchContainer/index.vue)

## 3) AI 助手入口与判定链路

- 主入口组件：[aiAnalysis-item.vue](file:///c:/Users/JYJY/Desktop/fupan-client/src/views/commonComponent/aiAnalysis-item.vue)
  - 典型复用入口：
    - [onlineAnalysis/aiAnalysis.vue](file:///c:/Users/JYJY/Desktop/fupan-client/src/views/pages/onlineAnalysis/aiAnalysis.vue)
    - [replay/aiAnalysis/only.vue](file:///c:/Users/JYJY/Desktop/fupan-client/src/views/modules/replay/aiAnalysis/only.vue)
    - [replay/online/aiAnalysis.vue](file:///c:/Users/JYJY/Desktop/fupan-client/src/views/modules/replay/online/aiAnalysis.vue)
- AI 助手页复用链路：
  - `aiAnalysis-item.vue`
  - `aiAnalysis/ai-contrast-only.vue`
  - `analysisLayout/component/wordDiscern.vue`
  - `DiscernSearchContainer/index.vue`
- 关键判定：
  - `DiscernSearchContainer` 中 `isAi=true` 表示 AI 助手上下文
  - 段落指标、报告切换、按钮显隐都依赖该标识
  - ROI 不应在 `isAi=true` 的链路中展示

# ROI 接口接入点

## 1) 单场 ROI 汇总

- 接口：`GET /openapi/v2000/getVideoRoi?videoId={videoId}`
- 前端封装：[request-api-back.js](file:///c:/Users/JYJY/Desktop/fupan-client/src/utils/request-api-back.js)
  - `this.$httpBack.v2000.getVideoRoi`
- 使用位置：
  - 详情页“投放数据” Tab 组件：[roiData/index.vue](file:///c:/Users/JYJY/Desktop/fupan-client/src/components/analysis/roiData/index.vue)

## 2) 在线曲线 ROI 字段

- 接口：`GET /openapi/v2100/onlineChartData?videoId={videoId}&step={step}`
- 客户端代理：`GET /anchorvideo/onlineChartData?videoId={videoId}`
- 曲线组装入口：
  - [curveData/index.vue](file:///c:/Users/JYJY/Desktop/fupan-client/src/components/analysis/curveData/index.vue)
  - [curveData/index.js](file:///c:/Users/JYJY/Desktop/fupan-client/src/components/analysis/curveData/index.js)
- 当前新增展示：
  - `qianchuanCostDataList -> 投放消耗`
  - `netTransactionRoiDataList -> 净成交ROI`
- 默认显隐规则：
  - 新增 ROI 曲线默认展示
  - `语速` 默认取消勾选

## 3) 段落 ROI 数据映射

- 核心归一化入口：[analysisMixin.js](file:///c:/Users/JYJY/Desktop/fupan-client/src/mixins/analysisMixin.js)
- 段落映射规则：
  - 与 `onlineNumList`、`barrageDataList` 一样，按段落 `startTimeSecond/endTimeSecond` 取时间范围内的第一条分时数据
  - 兼容字段名：`barrageNum / value / valueNum`
- 当前落到段落对象上的字段：
  - `item.qianchuanCost`
  - `item.netTransactionAmount`
- 段落展示入口：[DiscernSearchContainer/index.vue](file:///c:/Users/JYJY/Desktop/fupan-client/src/components/DiscernSearchContainer/index.vue)
  - 插在“语速”之前
  - 无值不展示
  - 仅普通云空间详情页展示

# 后续改动注意事项

- 若后端继续复用 `netTransactionRoiDataList` 字段名，但实际语义改为“净成交额/净成交ROI”中的任一一种，必须同步更新前端展示文案，避免字段名与 UI 语义错位。
- 若 ROI 未来要进入 AI 助手页，不能只改模板；必须重新审视 `isAi` 链路下的按钮、导出、右键菜单和报告内容，确认不会污染 AI 助手的信息密度。
- 若录制版未来也要支持 ROI，优先从 `versionSelection -> store.getVersionType/isPure -> controlTabs/DiscernSearchContainer` 这条判定链路切入，不要只在单个组件里硬编码放开。
