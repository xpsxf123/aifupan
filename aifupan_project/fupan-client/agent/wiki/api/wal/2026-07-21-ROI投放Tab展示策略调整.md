# 背景

在 ROI 接入后的首轮实现中，前端把“投放数据” Tab 的展示条件限制为 `online/webOnline + 单场视频 + 非快手 + 非短视频 + 非纯净版`，导致存在 ROI 数据时也可能因为前置条件过严而不展示 Tab，进而不会触发 `getVideoRoi`。

# 最新结论

- `投放数据` Tab 的展示口径调整为：
  - 非纯净版默认展示
  - 对比场景继续隐藏，因为当前 `getVideoRoi` 仍是单视频维度
- ROI 面板的数据加载口径调整为：
  - 只要当前详情存在 `videoId`，就允许调用 `this.$httpBack.v2000.getVideoRoi`
  - 若无 `videoId` 或接口无数据，则展示空态，而不是隐藏整个 Tab
- ROI 面板新增右上角 `千川授权` 按钮：
  - 仅在抖音自有账号且存在 `secUid` 时显示
  - 点击后复用主播列表中的 `this.$httpClient.qianchuan.authorizeQianchuan({ secUid })` 链路

# 影响文件

- `src/components/analysis/controlTabs.vue`
- `src/components/analysis/roiData/index.vue`

# 注意事项

- 若后续产品再次要求仅在特定场景展示 ROI，不要只改 `roiData/index.vue`，还要同步检查 `controlTabs.vue` 中的 Tab 显隐逻辑。
- 若 `getVideoRoi` 接口字段发生变化，优先在 `roiData/index.vue` 的字段归一化逻辑中兼容，不要把后端别名判断散落到模板层。
