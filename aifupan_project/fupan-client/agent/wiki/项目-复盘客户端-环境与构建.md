# 项目-复盘客户端-环境与构建

## 本文档用途

- 解释项目如何选择环境、如何注入接口地址、如何区分客户端形态与 Web 形态。
- 给后续排查“接口地址不对/资源路径不对/版本号不对”等问题提供唯一依据。

## 环境与目标

项目通过两组变量控制构建与运行：

- `RUN_ENV`：业务环境（development/test/release/production/custom）
- `BUILD_TARGET`：构建目标（默认客户端；当为 `website` 时走 Web 形态）

## 脚本入口（package.json）

脚本关键点：

- 开发：`serve`、`serve:test`、`serve:release`、`serve:prod`、`serve:custom`
- Web 开发：`serve:web`、`serve:release:web`
- 打包：`build`、`build:test`、`build:release`、`build:web` 等

说明：

- 这些脚本的本质是给 `vue-cli-service serve/build` 额外注入 `RUN_ENV/BUILD_TARGET`。
- 真实 URL 注入来源在 `ipConfig/index.js` 与 `vue.config.js` 的模板参数注入。

## ipConfig（接口地址与签名配置）

文件：`ipConfig/index.js`

### back（业务后端）

- test/development：`https://testapi.aifupan.com.cn/replay`
- release：`https://api-yz.aifupan.com.cn/replay`
- production：`https://api.aifupan.com.cn/replay`
- custom：空字符串（需要自行注入）

### client（客户端本地 API）

- test/development/production/release：`http://127.0.0.1:10086/api`（注释提示端口可能由客户端返回）
- custom：空字符串

### 其他

- `platform_code`：不同环境映射到 `client/cloudSpace/official`
- `signatureConfig`：不同环境的签名 `appId` 与 `signature key`

## vue.config.js（构建与模板注入）

### publicPath

- `BUILD_TARGET=website` 时：`/client`
- 否则：`./`

### HTML 注入变量（用于 window.SITE_CONFIG 等）

`vue.config.js` 会给 HTML 模板注入（示例字段）：

- `ENV`（中文环境名）
- `BUILD_TARGET`
- `BCAK_API_URL`、`CLIENT_API_URL`
- `BAIDU_HM_SRC`
- `buildInfo`（版本/环境等信息）

这些字段通常会在 `public/index.html` 或运行时脚本中写入 `window.SITE_CONFIG`，供请求层读取。

### 版本信息

- 优先 `process.env.VUE_APP_VERSION`
- 否则读取当前 git 分支名，并在非 production 时拼接 RUN_ENV

## 请求层如何使用这些配置

- 后端请求（back）：`baseURL = window.SITE_CONFIG.backApiURL`
- 客户端请求（client）：`baseURL = window.SITE_CONFIG.clientApiURL`
  - 并尝试从 UA 解析 `port=xxxx` 动态覆盖到 `http://127.0.0.1:${port}/api`

## 常见问题定位

- “接口地址不对”：先确认 `RUN_ENV` 是否正确 → 再确认 `window.SITE_CONFIG.backApiURL/clientApiURL` 是否被写入 → 再看 `ipConfig/index.js` 是否符合预期。
- “Web 环境调用 client 失败”：属于设计行为，`request-client` 在 Web 环境会直接 reject。
