# 项目-复盘客户端-组件资源清单

## 本文档用途

- 把项目内“可被复用/组合的组件资源”做一次可检索的初始化清单。
- 后续生成页面时，可先在这里选组件，再进入对应技能（self_skills）按模板组装。

## 清单口径

- 全局通用组件：`src/components/**/*.vue`
- 页面级通用组件：`src/views/commonComponent/**/*.vue`
- 模块内组件：`src/views/modules/**/component/**/*.vue`

说明：

- 本清单以“文件路径”为准；组件名以文件名/目录名为准（Vue SFC 内 name 可能不一致）。
