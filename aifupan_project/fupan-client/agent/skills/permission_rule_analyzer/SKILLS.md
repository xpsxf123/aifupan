# 权限规则分析器

## 技能目的
提取角色与权限点定义，建立角色权限映射与页面/元素权限控制规则，生成权限规则Markdown（内嵌json代码块）。

## 输入参数
- `brd_document`：必填，文本。BRD文档完整内容。

## 输出
- `permission_rules_md`：权限规则Markdown（内嵌```json代码块，详见模板）。

## 分析逻辑
1. 识别角色与描述、权限点集合。
2. 建立角色与权限映射关系。
3. 抽取页面访问权限与元素权限控制、无权限表现。
