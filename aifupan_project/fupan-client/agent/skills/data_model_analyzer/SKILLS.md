# 数据模型分析器

## 技能目的
从DRD文档提取需要在前端处理的数据实体、字段定义、枚举映射与关联关系，生成数据模型Markdown（内嵌json代码块）供展示与状态管理技能使用。

## 输入参数
- `drd_document`：必填，文本。DRD文档完整内容。

## 输出
- `data_model_md`：数据模型Markdown（内嵌```json代码块，详见模板）。

## 分析逻辑
1. 扫描DRD数据实体章节，提取实体与描述。
2. 提取字段类型、必填、唯一、长度、范围、格式与示例值。
3. 识别枚举及映射关系与实体关联。
4. 标识敏感字段与前端处理方式。
