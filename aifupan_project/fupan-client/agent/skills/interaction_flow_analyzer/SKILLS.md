# 交互流程分析器

## 技能目的
识别页面上的交互行为，包括触发元素、触发事件、执行动作、前置/后置、异常处理、页面跳转与弹窗显示，生成交互定义Markdown（内嵌json代码块）。

## 输入参数
- `frd_document`：必填，文本。FRD文档完整内容。
- `page_id`：选填，文本。指定分析页面ID。

## 输出
- `interaction_md`：交互定义Markdown（内嵌```json代码块，详见模板）。

## 分析逻辑
1. 扫描FRD交互流程章节，识别触发元素与事件。
2. 提取执行动作、前置条件、后置结果、涉及数据与接口。
3. 识别页面跳转、弹窗显示与异常处理方式。

## 模板
参见 `templates/schema.md`。

## 协同说明
- 输出的 `interaction_md` 可辅助 `需求-Mermaid原型生成器` 生成页面流程图
