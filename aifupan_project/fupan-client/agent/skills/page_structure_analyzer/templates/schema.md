# 页面结构（Markdown Code）

说明：以下为页面结构数据，采用 Markdown 文档内嵌 json 代码块，方便前端直接解析。

```json
{
  "项目名称": "{project_name}",
  "分析时间": "{date}",
  "页面清单": [
    {
      "页面ID": "{page_id}",
      "页面名称": "{page_name}",
      "页面路径": "{page_path}",
      "页面描述": "{page_desc}",
      "页面类型": "列表页|表单页|详情页|看板页",
      "包含元素": [
        {"元素ID": "{elem_id}", "元素名称": "{elem_name}", "元素类型": "表单|表格|视图|组件", "元素描述": "{elem_desc}", "业务含义": "{biz}"}
      ]
    }
  ]
}
```
