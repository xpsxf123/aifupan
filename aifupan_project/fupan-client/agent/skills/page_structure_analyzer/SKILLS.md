# 页面结构分析器

## 技能目的
从FRD文档中识别页面清单、页面路径与页面内元素层级及属性，生成结构化的页面结构Markdown（内嵌json代码块），供渲染技能消费。

## 触发时机
- 输入FRD并需要抽取页面与元素结构信息时。

## 输入参数
- `frd_document`：必填，文本。FRD文档完整内容。
- `target_pages`：选填，数组。指定要分析的页面ID列表，为空则分析全部页面。

## 输出
- `page_structure_md`：页面结构Markdown（内嵌```json代码块，详见模板）。

## 分析逻辑
1. 扫描FRD的界面元素章节，识别页面标题与描述。
2. 提取页面内各元素的类型、业务含义、数据字段与层级关系。
3. 表格提取列定义与分页配置，表单提取子元素字段定义。
4. 汇总为统一的页面结构JSON。

## 模板
参见 `templates/schema.md`，包含示例结构与字段说明。

## 协同说明
- 输出的 `page_structure_md` 可直接作为 `web-前端原型布局数据生成器` 的输入（支持解析md代码块）
