# 状态共享分析器

## 技能目的
识别需要在多个页面间共享或持久化的状态，以及页面本地状态的初始值与更新时机，生成状态定义Markdown（内嵌json代码块）。

## 输入参数
- `frd_documents`：必填，文本数组。多个页面的FRD文档。
- `brd_document`：必填，文本。BRD文档，用于场景与角色约束参考。

## 输出
- `shared_state_md`：状态定义Markdown（内嵌```json代码块，详见模板）。

## 分析逻辑
1. 识别跨页面共享的全局状态与持久化策略。
2. 识别每个页面的本地状态集合与初始值。
3. 定义状态更新时机与依赖。
