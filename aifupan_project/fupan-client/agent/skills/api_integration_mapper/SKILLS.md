# 前端-接口对接映射技能

## 目标

- 让前端能基于需求文档或核心 JSON 快速定位需要对接的接口
- 输出可执行的对接策略：依赖顺序、必填字段、权限态、失败兜底
- 同步输出“接口冒烟测试建议/配置草案”，支持测试侧复用

## 输入

- 需求资产（可选）：PRD/FRD/用例/页面清单
- 核心 JSON（推荐）：页面描述、功能点、动作绑定、字段规则
- 接口文档（推荐）：OpenAPI / 接口清单

## 输出

- 对接映射：
  - 页面/功能点 → 接口（method+path）清单
  - 每个接口的依赖输入（token/id/上下文）与输出数据去向
- 调用顺序与依赖图（文本/结构化）
- 冒烟测试建议：
  - 必填/类型/边界/权限态
  - 关键链路流程（登录→权限→角色→用户等）

## 工作步骤（推荐）

1. 从核心 JSON 提取页面与功能点（按钮/动作/表单）
2. 用接口文档匹配候选 endpoint（路径/字段/描述相似度）
3. 输出映射与置信度，并标注“待人工确认”
4. 生成依赖顺序与最小可跑链路
5. 生成冒烟建议，供测试智能体落盘为测试资产

## 边界

- 默认不直接改代码，只输出对接映射与建议
- 匹配结果必须标注置信度与待确认项，避免误对接
