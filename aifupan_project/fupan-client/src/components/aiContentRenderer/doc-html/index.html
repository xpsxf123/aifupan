AiContentRenderer 标签说明与样式预览（HTML 可导出 PDF）

本文件用于说明 mdTag 自定义标签、data-block、以及 [!##] 指令语法。每个标签都包含：用途说明、参数要求、示例输入与“最终渲染 HTML”样式预览。

提示：本 HTML 以静态方式展示“最终渲染 HTML”。真实业务中由 AiContentRenderer 解析 Markdown + aifupan 标签后输出相同结构与样式。

[!##] 指令（Markdown 指令 → aifupan 标签）

用途
在“纯 Markdown”中，用指令语法生成自定义标签，避免直接输出 HTML 标签。
开始指令

结束指令

自闭合指令
[!##!]{element="xxx", ...attrs}（等价于 <aifupan-xxx ... />）
属性语法
支持 key=value（可带引号/不带引号），以及“裸 token”布尔属性（如 resource-data）。
[!##]{element="note",title="提示"}

<aifupan-data-block>（结构化数据块：缓存 + 可选可视化）

用途
承载结构化数据（尤其是 JSON）。支持 “可见渲染” 与 “隐藏缓存”。隐藏时不展示，但会缓存数据供后续逻辑读取。
visible
true|false。默认 false（隐藏）。
type
当 visible=true 时建议必填，默认 structured。内置：structured、scriptQualityReport。
cacheKey
可选。作为缓存 key；不传会自动生成。
contentType
json|text|html。可选。若内部包含 fenced code（如 ```json）可自动推断；都没有时默认 text。
resource-data
可选布尔属性，用于标记“资源数据”（主要供后端截取/消费）。

用法 A：visible=false（隐藏，仅缓存）

<aifupan-data-block visible="false" cacheKey="k_resource" resource-data>
{"a":1,"b":2}
</aifupan-data-block>
预览
该 data-block 为隐藏模式：前端不会渲染内容，但会将数据缓存到 dataBlockStore（key = k_resource）。

用法 B：visible=true + type=structured（JSON 可视化）

<aifupan-data-block visible="true" type="structured" cacheKey="k1">
{"name":"张三","score":98,"tags":["A","B"]}
</aifupan-data-block>
预览（示意：structured 会渲染为 JSON 结构展示）
JSON 数据（structured）
name：张三
score：98
tags：["A","B"]

用法 C：visible=true + type=scriptQualityReport（话术质检报告 JSON）

<aifupan-data-block visible="true" type="scriptQualityReport" cacheKey="qc_1">
{"meta":{"roomName":"示例直播间"},"summary":{"totalNegativeCount":8}}
</aifupan-data-block>
预览（说明）
该 type 会挂载业务组件（scriptQualityReportContent）进行可视化渲染；本 HTML 文档不加载业务组件，故仅说明渲染位置与作用。

theme / skin（主题与皮肤）

用途
影响根容器的配色与背景质感。theme 影响变量色；skin 影响卡片质感（paper/glass/minimal）。
theme 值域

skin 值域
glass | paper | minimal
写法
既支持属性写法（<aifupan-theme name="business">），也支持写进标签名（<aifupan-theme-business />）。
<aifupan-theme name="business" />
<aifupan-skin name="paper" />

tag / badge（徽标）

tag
保留 success / warning / danger / error / info / default 语义色，同时新增 <aifupan-tag-1> 到 <aifupan-tag-30> 编号色。
自定义色
color 控制文字色；bgColor 控制背景基准色。无论只传 color 还是同时传 color + bgColor，背景与边框都会自动转成透明色，而不是直接使用纯实色。
badge
<aifupan-badge>，常用于“状态/提示”。

<aifupan-badge>未读</aifupan-badge>
