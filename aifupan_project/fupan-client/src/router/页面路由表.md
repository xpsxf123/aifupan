# 页面路由表

## 说明

- 路由来源分为两部分：
  - `src/router/index.js` 中的静态路由
  - `src/assets/json/menu.json` 中通过动态菜单挂载的业务路由
- 以下页面名称优先参考客户端左侧导航和路由 `meta.title`
- 表格按“页面名称 / URL”格式整理，便于直接复制到文档或表格工具中

## 动态参数说明

| 页面名称 | URL |
| --- | --- |
| 参数说明-`:id` | 业务主键，常见为 `videoId`、`fileId`、`contrastId`、`shareId` |
| 参数说明-`:type` | 页面类型标识，常见于只读页、分享页、在线分析页 |
| 参数说明-`:fileType` | 文件类型标识，常见值为 `video` 或 `file` |
| 参数说明-`:path*` | 通配路径参数，供中转页使用 |
| 参数说明-`/online/*/...` | 云空间泛型子路由，实际会挂到具体子页面下 |
