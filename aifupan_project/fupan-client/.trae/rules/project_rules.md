所有说明注释，文件说明使用中文。
在每个文件头部加入当前文件功能说明。
注释方式使用jsdoc注释方式。
所有 *.js/*.ts/*.vue 文件在文件头部必须写“当前文件功能说明”（中文）。
函数与对象必须使用标准 JSDoc 注释（@description/@param/@returns 等），且参数/返回值类型尽量明确。
复杂逻辑或代码量较大时，必须增加必要的单行注释解释关键步骤与约束，便于后续 AI/人类二次维护与升级理解（不要求机械逐行注释）。
公共scss文件在src/assets/scss中引入。
封装的组件在src/components中创建。
枚举文件在src/enums中创建，使用格式请参考index.js头部的注释代码。将参数值和label分为2部分。并且将枚举分类储存在不同文件中，如果没有分类文件，生成分类文件在创建枚举方便管理。
组件生成时请按照模块划分，每个模块创建一个文件夹，文件夹名称为模块名称，文件夹中包含组件文件和组件的scss文件。
每个组件请简化功能，最大可能实现单功能，在通过单功能组合生成多功能组件，并且每个组件最多代码数不超过400行。
功能函数存放在utils文件夹中。
各种格式化文件存放在src\utils\utils.js文件夹中，如果函数功能不能完成格式化的情况，请将新生成的格式化函数存放到utils.js文件夹中。
将功能按照组件功能进行分类，每个组件功能分类创建一个文件夹，文件夹名称为组件功能分类名称，文件夹中包含组件文件和组件的scss文件。
将功能块分文件存放，每个功能块创建一个文件，文件名称为功能块名称，文件中包含功能块的代码。
将业务代码中的弹窗，表单，表格等功能块封装成组件，组件名称为功能块名称，组件文件存放在components文件夹中。
将业务代码中的复杂结构组件也按照复杂程度，化分模块进行封装，组件名称为功能块名称。
如果封装的组件具有公用性，将组件文件存放在components文件夹中，否则将组件文件存放在src\views\modules\模块名称\components文件夹中。
CoreTable组件的column配置属性中，除了slot插槽外，render的实现参考方案为：
{
    label: '录制时间',
    prop: 'startTime',
    option: {
        width: '150px',
        render: (row) => {
            return (`<div class="recordColContainer">
                <div>${row?.startTime?.substring(0, 16)}</div>
                <div style="line-height: 0.6;">~</div>
                <div>${row?.endTime?.substring(0, 16)}</div>
            </div>`)
        },
    },
}
通过option下的render，并且接受参数row，row为当前行数据，使用jsx语法，返回值为html字符串。
如果是简单格式化的情况使用格式化案例：
{
    label: '话术',
    prop: 'script',
    formatter: (row) => row.analysisStatus===2?'导出':'-',
}
此方法使用formatter接受参数row，row为当前行数据,直接输出需要的文本数据。

版本变更记录规则：
1. 版本变更记录文件统一放在 docs/版本变更/ 目录下，文件名为 <版本号>.md。
2. 写入版本变更记录前必须调用 `version_change_log` skill，由 skill 内部执行新终端 Git 分支号查询与版本校验。
3. 若版本变更记录文件版本号与当前分支版本号不一致，必须删除或回滚该文档编辑，并阻止提交。
4. 变更来源：仅从 test-xxx 和 reslease-xxx 分支的代码变更中提取，不再从 dev-xxx 分支提取。
5. 版本变更文件末尾需包含「版本功能明细」表格，列出当前版本完整功能清单供测试验收使用。

版本开发目录规则：
1. dev-xxx 微分支的开发记录存放在 docs/版本开发目录/<大版本号>.md 中。
2. 每个功能分支（如 dev-2.6.3.1）在对应大版本文件（如 2.6.3.md）中占一个章节。
3. 章节格式：## X.Y.Z.W 分支，包含功能名称、变更时间、变更文件、功能描述、合并状态。
4. dev 分支合并到 test/reslease 时，自动将功能描述摘要写入版本变更文件。
5. aiDev-* 分支（Agent 自动派发）不进行开发记录维护。
