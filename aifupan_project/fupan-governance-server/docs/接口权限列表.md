## 统计汇总

**总计：50个带权限控制的API接口**

### 按业务模块分类：
- **组织管理模块**：16个接口
- **RBAC权限管理模块**：16个接口（含1个测试接口）
- **直播间管理模块**：15个接口

### 按权限前缀分类：
- `org:*` - 组织管理权限：16个
- `sys:*` - 系统管理权限：16个
- `room:*` - 直播间管理权限：15个

### 注意事项：
1. 部分接口支持多个权限标识（如修改接口需要 update 或 add 权限）
2. 业绩管理模块（performance）的接口使用的是 `@RequiredLogin` 而非 `@Permissions`，表示只需登录即可访问，不需要特定权限
3. RbacTestController 已被注释，实际不生效
