# 核心业务流程图 - 活动奖励域

## 一、邀请奖励发放流程

```
触发事件（注册/下载/使用/AI）
    │
    ▼
┌──────────────────────────────┐
│ ClientInviteRewardRecordBll  │
│ .giveUserInviteAward()       │
│ @Transactional               │
└────────────┬─────────────────┘
             │
             ▼
┌──────────────────────────────┐
│ 1. 验证用户设备指纹          │
│    validUserFingerprint()    │
│    - 注册: 新设备才发放       │
│    - 下载: Web不发,客户端新设备│
│    - 使用/AI: 新设备才发放    │
└──────┬───────────────────────┘
       │
       ├── 指纹验证失败 → 不发放奖励
       │
       ▼ 验证通过
┌──────────────────────────────┐
│ 2. 验证邀请关系有效性        │
│    - 查询邀请人信息           │
│    - 检查邀请人和被邀请人     │
│      租户ID                  │
└──────────┬───────────────────┘
           │
           ▼
┌──────────────────────────────┐
│ 3. 查询或创建奖励记录        │
│    createRewardRecord()      │
│    - 查询邀请人活动进度和奖励 │
│    - 查询被邀请人活动进度和奖励│
│    - 为邀请人创建奖励记录     │
│    - 为被邀请人创建奖励记录   │
│    - 批量保存                │
└──────────┬───────────────────┘
           │
           ▼
┌──────────────────────────────┐
│ 4. 组装奖励数据              │
│    - 奖励类型: 版本升级(0)   │
│    - 奖励类型: 增量包(1)     │
└──────────┬───────────────────┘
           │
           ▼
┌──────────────────────────────┐
│ 5. 调用订单模块发送奖励      │
│    OrderFeign.addActivityOrder│
│    - 版本升级: 创建升级订单   │
│    - 增量包: 创建增量包订单   │
└──────────┬───────────────────┘
           │
           ▼
┌──────────────────────────────┐
│ 6. 修改发放状态为已发放      │
└──────────────────────────────┘
```

## 二、邀请活动管理流程

```
后台创建邀请活动
    │
    ▼
┌──────────────────────────┐
│ ClientInviteActivityBll  │
│ .save() @Transactional   │
└────────┬─────────────────┘
         │
         ▼
┌──────────────────────────┐
│ 1. 保存活动基本信息      │
│    ClientInviteActivity  │
└────────┬─────────────────┘
         │
         ▼
┌──────────────────────────┐
│ 2. 保存邀请进度          │
│    ClientInviteProgress  │
│    (如: 邀请1人/3人/5人) │
└────────┬─────────────────┘
         │
         ▼
┌──────────────────────────┐
│ 3. 保存进度奖励          │
│    ClientInviteProgress  │
│    Reward                │
│    (每个进度对应的奖励)  │
└──────────────────────────┘


客户端查看活动
    │
    ▼
┌──────────────────────────┐
│ infoByClient()           │
│ 1. 获取默认邀请活动      │
│ 2. 获取邀请人进度列表    │
│ 3. 填充奖励信息          │
│    (版本名称、增量包数量)│
│ 4. 转换商品数量单位      │
└──────────────────────────┘
```

## 三、奖励汇总查询流程

```
客户端请求奖励汇总
    │
    ▼
┌──────────────────────────┐
│ clientGetRewardSummary() │
└────────┬─────────────────┘
         │
         ▼
┌──────────────────────────┐
│ 1. 获取用户邀请码        │
└────────┬─────────────────┘
         │
         ▼
┌──────────────────────────┐
│ 2. 统计总邀请人数        │
└────────┬─────────────────┘
         │
         ▼
┌──────────────────────────┐
│ 3. 按商品类型分组统计    │
│    - 版本套餐: 合并时长  │
│    - 增量包: 合并数量    │
└────────┬─────────────────┘
         │
         ▼
┌──────────────────────────┐
│ 4. 返回 RewardSummaryVo  │
│    List                  │
└──────────────────────────┘
```
