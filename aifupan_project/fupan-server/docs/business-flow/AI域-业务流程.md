         ▼

## 二、HTML报告生成流程

```
用户请求生成HTML报告
    │
    ▼
┌──────────────────────────┐
│ serviceGenerateHtml()    │
└────────┬─────────────────┘
         │
         ▼
┌──────────────────────────┐
│ 1. 前置检查              │
│    - 检查是否已在生成中  │
│    - 修改状态为生成中    │
└────────┬─────────────────┘
         │
         ▼
┌──────────────────────────┐
│ 2. 异步执行(@Async)      │
└────────┬─────────────────┘
         │
         ▼
┌──────────────────────────┐
│ 3. 调用AI生成HTML        │
│    (火山引擎Ark)         │
└────────┬─────────────────┘
         │
    ┌────┴────┐
    ▼         ▼
  成功      失败/超时(20min)
    │         │
    ▼         ▼
┌────────┐ ┌────────────┐
│记录Token│ │标记为失败   │
│消耗     │ └────────────┘
└───┬────┘
    │
    ▼
┌──────────────────────────┐
│ 4. 上传HTML到OSS         │
│    (阿里云OSS)           │
└────────┬─────────────────┘
         │
         ▼
┌──────────────────────────┐
│ 5. 更新生成状态为完成    │
└──────────────────────────┘
```

         │
         ▼

         │
         ▼
┌──────────────────────────┐

└────────┬─────────────────┘

└────────┬─────────────────┘
         │
