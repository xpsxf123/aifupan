# 核心业务流程图 - 订单域

## 一、订单创建与支付流程

```
用户发起购买
    │
    ▼
┌─────────────────┐
│ 选择套餐/增量包  │
│ (版本升级/续费/  │
│  购买增量包)     │
└────────┬────────┘
         │
         ▼
┌─────────────────┐     ┌──────────────┐
│ OrderLogic      │────▶│ 工厂模式     │
│ .createClient   │     │ 按商品类型   │
│  Order()        │     │ 选择创建器   │
└────────┬────────┘     └──────────────┘
         │
         ▼
┌─────────────────┐
│ 创建订单记录     │
│ - 订单主表       │
│ - 订单详情       │
│ - 订单扩展       │
│ - 支付单         │
│ 状态: 0-待支付   │
└────────┬────────┘
         │
         ▼
┌─────────────────┐
│ 生成支付信息     │
│ - 支付宝二维码   │
│ - 微信支付二维码 │
│ 返回CreateOrderVo│
└────────┬────────┘
         │
    ┌────┴────┐
    ▼         ▼
 支付成功   超时未支付
    │         │
    ▼         ▼
┌────────┐ ┌────────────┐
│支付回调 │ │OrderPayBll │
│验证签名 │ │.orderExpired│
│        │ │状态→6已过期 │
└───┬────┘ └────────────┘
    │
    ▼
┌─────────────────┐
│ OrderPayBll     │
│ .paySuccessHandle│
│ @Synchronized   │
│ - 验证订单状态   │
│ - 更新支付单→1  │
│ - 记录交易ID    │
└────────┬────────┘
         │
         ▼
┌─────────────────┐
│ OrderBll        │
│ .successOrder() │
│ @Transactional  │
└────────┬────────┘
         │
    ┌────┴────────────┐
    ▼                 ▼
升级订单           普通订单
    │                 │
    ▼                 ▼
┌────────────┐  ┌────────────┐
│停用旧版本   │  │ useOrder() │
│订单         │  │            │
│冻结免费版   │  │            │
└─────┬──────┘  └─────┬──────┘
      │               │
      └───────┬───────┘
              ▼
┌─────────────────────┐
│ OrderBll.useOrder() │
│ - 订单状态→2生效中   │
│ - 订单详情状态→1     │
│ - 为主用户添加资产   │
│ - 为子用户添加资产   │
│ - 统计总资产         │
│ - 更新套餐缓存       │
└─────────────────────┘
```

## 二、订单过期处理流程

```
定时任务触发（XXL-Job）
    │
    ▼
┌──────────────────────────┐
│ batchExpiredOrderProcessing│
│ 查询所有到期订单           │
└────────────┬─────────────┘
             │
             ▼
┌──────────────────────────┐
│ 批量停用过期订单          │
│ 订单状态 2→3(已停用)      │
│ 订单详情状态→2(已停用)    │
└────────────┬─────────────┘
             │
             ▼
┌──────────────────────────┐
│ 检查是否有待开始的订单    │
│ (状态=1的订单)            │
└──────┬───────────┬───────┘
       │           │
    有待开始     无待开始
       │           │
       ▼           ▼
┌────────────┐ ┌────────────────┐
│ 激活该订单  │ │ 解冻用户订单    │
│ 状态1→2    │ │ (状态4→恢复)   │
└────────────┘ └───────┬────────┘
                       │
                       ▼
               ┌────────────────┐
               │ 检查用户是否有  │
               │ 有效版本        │
               └──┬──────────┬──┘
                  │          │
                有版本     无版本
                  │          │
                  ▼          ▼
               (结束)  ┌────────────┐
                       │ 创建免费版本│
                       │ 订单        │
                       └─────┬──────┘
                             │
                             ▼
                       ┌────────────┐
                       │ 统计用户资产│
                       └────────────┘
```

                    ┌──────────┐

                    ┌────────┐      │

                        │
           ┌────────────┼────────────┐

     ┌──────────┐ ┌──────────┐ ┌──────────┐
