# 核心业务流程图 - 代理分销域

## 一、代理商创建流程

```
后台创建代理商
    │
    ▼
┌─────────────────────┐
│ AgentBll.save()     │
│ @Transactional      │
└────────┬────────────┘
         │
         ▼
┌─────────────────────┐
│ 1. 验证佣金比例     │
│    (0-100%)         │
└────────┬────────────┘
         │
         ▼
┌─────────────────────┐
│ 2. 检查渠道是否     │
│    已关联代理商      │
└────────┬────────────┘
         │
         ▼
┌─────────────────────┐
│ 3. 检查手机号重复   │
└────────┬────────────┘
         │
         ▼
┌─────────────────────┐
│ 4. 生成邀请链接code │
└────────┬────────────┘
         │
         ▼
┌─────────────────────┐
│ 5. 判断代理商类型   │
└──────┬──────────┬───┘
       │          │
  agentType=0   其他类型
  (普通代理商)     │
       │          │
       ▼          ▼
┌────────────┐  (跳过)
│ 创建后台   │
│ 用户账号   │
└─────┬──────┘
      │
      ▼
┌─────────────────────┐
│ 6. 保存代理商信息   │
└─────────────────────┘
```

## 二、代理商佣金结算流程

```
用户通过代理商渠道下单
    │
    ▼
┌─────────────────────┐
│ 订单完成(支付成功)   │
└────────┬────────────┘
         │
         ▼
┌─────────────────────┐
│ 查询订单关联的渠道   │
│ 和代理商信息         │
└────────┬────────────┘
         │
         ▼
┌─────────────────────┐
│ 计算佣金             │
│ = 订单金额 × 佣金比例│
└────────┬────────────┘
         │
         ▼
┌─────────────────────┐
│ 创建佣金记录         │
│ AgentCommissionEntity│
└────────┬────────────┘
         │
         ▼
┌─────────────────────┐
│ 佣金结算             │
└─────────────────────┘
```

## 三、渠道树形结构

```
平台渠道(根)
├── 渠道A (代理商1)
│   ├── 子渠道A-1
│   └── 子渠道A-2
├── 渠道B (代理商2)
│   ├── 子渠道B-1
│   │   └── 子渠道B-1-1
│   └── 子渠道B-2
└── 渠道C (直营)
    └── 子渠道C-1
```
