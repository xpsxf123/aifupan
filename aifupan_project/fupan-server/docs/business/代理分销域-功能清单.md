# 业务功能清单 - 代理分销域

> 模块: replay-agent | 路径前缀: replay/agent, replay/agentcommission, replay/channel, replay/agentsale 等

## 一、代理商管理

| 功能 | 说明 | 关键类 |
|------|------|--------|
| 代理商CRUD | 创建/修改/删除/查询代理商 | AgentBll |
| 代理商创建 | 验证佣金比例→检查渠道→生成邀请码→创建后台用户 | AgentBll.save |
| 代理商状态管理 | 启用/禁用代理商，同步修改后台用户状态 | AgentBll.updateAgentStatus |
| 员工状态管理 | 批量修改代理商下销售员工状态 | AgentBll.updateEmployeeStatus |
| 当前用户代理信息 | 代理商用户获取自己的代理商信息 | AgentController.currentUserInfo |

**代理商类型**: 0-普通代理商（需创建后台用户），其他-特殊代理商

## 二、渠道管理

| 功能 | 说明 |
|------|------|
| 渠道CRUD | 渠道的增删改查 |
| 渠道树形结构 | 获取渠道的树形层级列表 |
| 子渠道查询 | 获取渠道所有子渠道ID |

## 三、佣金管理

| 功能 | 说明 |
|------|------|
| 佣金CRUD | 佣金规则的增删改查 |
| 佣金结算记录 | 按代理商查询佣金结算记录 |
| 分佣处理 | 订单完成后自动计算和分配佣金 |

## 四、销售管理

| 功能 | 说明 |
|------|------|
| 代理商销售CRUD | 代理商下销售人员管理 |
| 平台销售管理 | 平台直属销售人员管理 |
| 推广渠道管理 | 代理商推广渠道的增删改查 |
| 销售-渠道关联 | 销售人员与推广渠道的关联管理 |
| 按渠道查销售 | 通过渠道ID查询关联的销售列表 |

## 五、邀请链接

| 功能 | 说明 |
|------|------|
| 邀请链接CRUD | 邀请链接code的增删改查 |
| 获取用户邀请链接 | 当前用户获取自己的邀请链接 |
| 根据code查信息 | 通过邀请code获取邀请信息 |
