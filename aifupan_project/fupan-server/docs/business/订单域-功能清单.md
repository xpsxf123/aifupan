# 业务功能清单 - 订单域

> 模块: replay-order | 路径前缀: replay/order, replay/orderpay, replay/commodity, replay/package, replay/userproperty

## 一、订单管理

### 1.1 订单生命周期
- **订单状态**: 0-待支付, 1-待开始, 2-生效中, 3-已停用, 4-已冻结, 5-已升级, 6-已过期, 8-已编辑
- **订单类型**: 0-免费订单, 1-升级订单, 2-免费版升级, 6-编辑订单, 7-活动订单

### 1.2 核心功能
| 功能 | 说明 | 关键类 |
|------|------|--------|
| 创建订单 | 通过工厂模式按商品类型创建，支持在线支付/邀请码/后台创建 | OrderBll.createOrder |
| 在线支付订单 | 创建支付宝/微信支付订单，返回支付二维码 | OrderLogic.createClientOrder |
| 订单完成 | 停用旧订单→支付处理→添加用户资产→更新状态 | OrderBll.successOrder |
| 订单过期处理 | 停用过期订单→激活待开始订单→解冻→创建免费版 | OrderBll.expiredOrderProcessing |
| 批量过期处理 | 定时任务批量处理过期订单 | OrderBll.batchExpiredOrderProcessing |
| 版本升级 | 从低版本升级到高版本套餐 | OrderLogic.pcUpgradeOrder |
| 版本续费 | 续费当前版本套餐 | OrderLogic.pcRenewalOrder |
| 购买增量包 | 购买额外的AI Token等增量资源 | OrderLogic.pcIncrementsOrder |
| 订单编辑 | 后台修改订单信息 | OrderLogic.orderEdit |
| 取消订单 | 取消待支付订单 | OrderLogic.orderStop |
| 关闭订单 | 关闭订单并调用支付平台关单 | OrderLogic.closeOrder |
| 免费版升级 | 从激活版升级到免费版 | OrderLogic.updateFreeVersion |

### 1.3 支付处理
| 功能 | 说明 | 关键类 |
|------|------|--------|
| 支付成功回调 | 验证签名→更新支付单→触发订单完成 | OrderPayBll.paySuccessHandle |
| 订单超时 | 支付超时→修改支付单和订单状态为已过期 | OrderPayBll.orderExpired |
| 支付宝支付 | Native扫码支付 | Alipay.nativePay |
| 微信支付 | 微信支付v3 | 微信支付回调 |
