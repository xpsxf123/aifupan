# 业务功能清单 - 活动与奖励域

> 模块: replay-activity, replay-reward
> 路径前缀: replay/activity/clientinviteactivity, replay/reward/clientinviterewardrecord

## 一、邀请活动管理

| 功能 | 说明 | 关键类 |
|------|------|--------|
| 活动CRUD | 邀请活动的增删改查 | ClientInviteActivityBll |
| 创建活动 | 保存活动+进度+奖励信息（事务） | ClientInviteActivityBll.save |
| 更新活动 | 修改活动→禁用旧进度→保存新进度和奖励 | ClientInviteActivityBll.update |
| 客户端获取活动 | 获取默认活动+进度列表+奖励信息 | ClientInviteActivityBll.infoByClient |

## 二、邀请进度

| 功能 | 说明 |
|------|------|
| 进度列表 | 按活动ID查询邀请进度 |
| 客户端获取进度和奖励 | 获取当前用户的邀请进度和对应奖励 |

## 三、奖励发放

| 功能 | 说明 | 关键类 |
|------|------|--------|
| 发放邀请奖励 | 验证指纹→验证邀请关系→创建记录→发放→更新状态 | ClientInviteRewardRecordBll.giveUserInviteAward |
| 创建奖励记录 | 为邀请人和被邀请人分别创建奖励记录 | ClientInviteRewardRecordBll.createRewardRecord |
| 用户指纹验证 | 防作弊：验证设备指纹，防止同设备多用户领取 | ClientInviteRewardRecordBll.validUserFingerprint |
| 客户端奖励汇总 | 统计总邀请人数、按商品类型分组统计奖励 | ClientInviteRewardRecordBll.clientGetRewardSummary |
| 后台奖励列表 | 支持按邀请人/被邀请人查询，填充用户信息 | ClientInviteRewardRecordBll.listByBack |
| 客户端奖励列表 | 客户端获取用户的邀请奖励列表 | clientGetUserRewardList |

**奖励场景**: 注册、下载、使用、AI
**奖励类型**: 0-版本套餐升级, 1-增量包
**防作弊机制**: 设备指纹验证，新设备才发放奖励
