# 爱复盘（ifupan）服务端 - 项目架构文档

## 一、项目概览

- **项目名称**: fupan-server（爱复盘）
- **技术栈**: Spring Boot 3.3.0 + Java 17 + MyBatis-Plus 3.5.6
- **构建工具**: Maven 多模块
- **包名前缀**: `com.jiuyu.replay`
- **启动类**: `com.jiuyu.replay.api.ReplayApiApplication`
- **端口**: 6606（dev/prod/yz）、6607（test）

## 二、模块结构与职责

```
fupan-server (父POM)
├── replay-api          # 主应用入口，聚合所有模块，包含Controller路由和全局配置
├── replay-common       # 公共基础库：工具类、基础实体、Redis封装、分布式锁
├── replay-generic      # 通用组件：跨模块的BO/DTO/VO/Feign接口定义
├── replay-power        # 权限管理：用户、角色、菜单、租户、部门
├── replay-order        # 订单管理：订单、商品、套餐、邀请码、用户资产
├── replay-agent        # 代理分销：代理商、渠道、佣金、销售
├── replay-activity     # 活动管理：邀请活动、进度追踪
├── replay-reward       # 奖励系统：邀请奖励发放、记录
├── replay-words        # 文案处理：视频文案提取、分析、敏感词、数据模型
├── replay-ai           # AI功能：AI对话、诊断报告、自定义提示词
├── replay-third        # 第三方集成：支付、OSS、短信、语音识别、AI模型
├── replay-system       # 系统配置：字典、登录图片等系统级功能
├── replay-video        # 短视频：视频提取、分组、热搜、达人管理
└── sql/                # 数据库SQL脚本
```

## 四、分层架构

项目采用自定义分层架构，各层职责如下：

```
Controller (API层)
    ↓
Logic (replay-api中的编排层，组合多个Bll调用)
    ↓
Bll (Business Logic Layer，核心业务逻辑)
    ↓
Rse (Resource Service，资源服务封装层)
    ↓
Service / ServiceImpl (MyBatis-Plus的Service层)
    ↓
Dao (数据访问层，继承BaseMapper)
    ↓
Entity (数据库实体)
```

**数据对象约定**：
- `Entity`: 数据库表映射实体
- `Bo`: Business Object，接收前端请求参数
- `Vo`: View Object，返回给前端的视图对象
- `Dto`: Data Transfer Object，模块间数据传输
- `Producer`: 各模块对外暴露的Feign接口实现

**跨模块调用方式**：
- 通过 `replay-generic` 中定义的 Feign 接口
- 各模块实现 Producer 接口供其他模块调用

## 五、关键技术组件

### 5.1 数据存储
- **MySQL**: 主数据库（阿里云RDS），HikariCP连接池（max=128）
- **MongoDB**: 视频内容、AI分析数据、弹幕等非结构化数据
- **Redis**: 缓存、分布式锁、会话管理（Lettuce客户端）
- **阿里云TableStore**: 弹幕数据、主播用户数据

### 5.2 消息队列
- **RocketMQ v5**: 异步消息处理
  - Topic标签: 用户邀请活动、用户首单、注册发短信

### 5.3 定时任务
- **XXL-Job 3.0.0**: 分布式定时任务调度

### 5.4 缓存体系
- **多层缓存**: Caffeine本地缓存 + Redis分布式缓存
- **弹性缓存**: ResilientRedisTemplate（Redis故障时降级到本地缓存）
- **缓存TTL**: 默认600秒

### 5.5 分布式锁
- **Redisson**: 分布式锁实现
- **HybridLockService**: 混合锁服务
- **@RepeatSubmit**: 防重复提交切面

### 5.6 第三方服务集成
| 服务 | 提供商 | 用途 |
|------|--------|------|
| 支付 | 支付宝 + 微信支付v3 | 在线支付 |
| 对象存储 | 阿里云OSS + 腾讯COS + 七牛云 | 文件/图片/视频存储 |
| 短信 | 阿里云SMS + 联麓短信 | 验证码、通知 |
| 语音识别 | 腾讯云ASR | 视频转文字 |
| 视频点播 | 腾讯云VOD | 视频处理 |
| AI大模型 | 火山引擎Ark（豆包/DeepSeek） | AI对话、诊断 |
| 内容审核 | 阿里云Green | 敏感内容检测 |
| 数据平台 | 抖音开放平台、蝉妈妈 | 直播数据 |
| 监控 | SkyWalking 9.4.0 | 链路追踪 |
| 通知 | 钉钉机器人 | 告警通知 |

### 5.7 安全机制
- **Jasypt**: 配置文件敏感信息加密（PBEWithMD5AndDES）
- **签名验证**: 接口请求签名校验（过期时间900秒）
- **雪花算法**: 分布式ID生成（SnowflakeManager）

## 六、启用的Spring特性

- `@EnableScheduling` - 定时任务
- `@EnableCaching` - 缓存
- `@EnableAsync` - 异步处理
- `@EnableAspectJAutoProxy` - AOP代理
- `@EnableMongoRepositories` - MongoDB支持
