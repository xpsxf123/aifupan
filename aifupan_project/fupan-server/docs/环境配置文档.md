## 六、日志配置

**配置文件**: `replay-api/src/main/resources/logback-spring.xml`


| 环境   | 日志级别  | 日志路径                             |
| ---- | ----- | -------------------------------- |
| dev  | DEBUG | D:/replay/logs/fupan-server      |
| test | DEBUG | /myApps/replay/logs/fupan-server |
| yz   | INFO  | /mnt/deploy/replay-api/logs      |
| prod | INFO  | /myApps/replay/logs/fupan-server |


- 输出: CONSOLE + FILE_ALL/INFO/WARN/ERROR（异步写入）
- 轮转: 按日期分目录, 单文件100MB, 总量10-20GB, 保留30-60天
- 集成SkyWalking GRPC日志上报
- 格式: `%d{yyyy-MM-dd HH:mm:ss.SSS} [%thread] %-5level [%X{traceId}] %logger{50} - %msg%n`
