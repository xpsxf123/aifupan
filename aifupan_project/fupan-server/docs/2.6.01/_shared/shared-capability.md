## 2. 公共产品问题

- 共同解决的问题：主播话术执行、弹幕互动回复、话术质量目前依赖人工巡查，效率低、主观性强、问题发现滞后。

## 5. 公共权限与资源校验

| 规则 | 统一口径 | 适用 REQ | 用户可见失败输出 |
|---|---|---|---|
| 账号类型 | 仅自有账号可见和可用，竞品账号无入口 | 全部 | 竞品账号入口展示 `-` 或隐藏 |
| 套餐版本 | 企业版、旗舰版、集团版支持，版本不足提示升级 | 全部 | 提示升级 |
| 授权量 | 授权量为租户共享监控位池；`addOrUpdateAnchor` 提交开启时按「直播间 × 功能」校验并占用 1 位，关闭时释放；扣减用幂等键防开关反复切换多扣；手动生成只校验当前版本是否有授权量，不校验剩余量 | 全部 | 各能力分别提示授权数量不足并联系产品顾问购买增量包 |
| Token / 算力 | 三项 AI 监控统一最低门槛为 10 万 Token；自动生成和手动生成报告前均校验 Token | 全部 | `您的算力数量不足，请联系产品顾问购买。` |
| 配置开关 | 自动生成依赖直播间对应开关；手动生成不要求对应开关已开启 | 全部 | 手动生成仍需满足套餐功能权限、自有账号和 Token |

账号类型切换补充规则：用户编辑直播间时，如果要从自有账号切换为同行业 / 竞品账号，且该直播间已开启任一 AI 监控能力，应先提示用户关闭对应 AI 监控功能后再提交修改；关闭后释放对应功能授权占用。`REQ-2026-0508-话术质检` 已按此规则确认。

## 7. 公共异常与边界

| 场景 | 统一处理 | 用户可见输出 | 子 REQ 是否需要补充 |
|---|---|---|---|
| 竞品账号 | 不展示入口 | `-` 或隐藏 | 是 |
| 已开启监控的自有账号改为同行业 / 竞品账号 | 阻断保存，要求先关闭对应监控功能 | 提示先关闭对应 AI 监控功能后再提交修改 | 是 |
| 版本不足 | 阻止开启或生成 | 提示升级 | 是 |
| 授权量不足 | 阻止开启自动监控或保存；手动生成不校验授权数量 | 按能力显示授权数量不足文案 | 是 |
| 算力不足 | 阻止报告生成 | `您的算力数量不足，请联系产品顾问购买。` | 是 |
| 报告内容过长 | 报告区域出现滚动条 | 滚动到底部后可确认已读 | 是 |

## 8. 公共发布策略

- 发布顺序：服务端生成能力和客户端前端展示必须同版本就绪后再对用户开放。
- 任一端未就绪时用户侧表现：完全隐藏用户侧开关、列表列、红点和报告入口，不暴露半成品能力。
- 是否允许单个子能力先灰度：已确认允许。单个子能力先灰度时，未开放能力必须完全隐藏入口、列表列、红点和报告。
- 回滚时共同处理：回滚能力必须隐藏入口、列表列、红点、报告入口和手动生成按钮；已有报告是否继续展示由对应子 PRD 或实施期灰度方案确认。
