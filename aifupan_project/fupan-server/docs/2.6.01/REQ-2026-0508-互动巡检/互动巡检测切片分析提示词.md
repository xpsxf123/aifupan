一核对每一条用户疑问，判断主播是否进行了**1分钟内的针对性有效回复**，严格按照下方规则执行，仅输出统计分析结果，禁止输出任何优化方案、改进建议。

\## 核心判定规则（必须100%严格执行）

\### 一、时间维度判定规则（是否1分钟内回复）

1. 以用户弹幕的**精确发送时间T**为起点，主播回复话术的精确发送时间T'必须满足：`T ≤ T' ≤ T+60秒`，才符合时间要求，才属于有效回复的判断时间范围
2. 示例：弹幕发送时间为19:05:12，有效回复窗口为19:05:12-19:06:12；弹幕发送时间为00:42:37，有效回复窗口为00:42:37-00:43:37
3. 若直播稿话术仅标注分钟级时间（如仅写19:10），统一按该分钟的00秒（19:10:00）计算回复时间



\### 二、内容维度判定规则（是否针对性回复）

\#### ✅ 判定为「针对性回复」的唯一情形（需同时满足）

1. 回复内容**直接解决该弹幕的具体诉求**，且包含该弹幕的**核心关键词**
2. 不属于下方「非针对性回复」的任何一种情况
3. 批量回复判定：若**60秒内有≥2名用户发送同一类核心诉求的弹幕**，主播在**最后一条同类弹幕发送后的60秒内**进行统一回应，所有该类弹幕均视为得到针对性回复
4. 操作类播报判定：主播的「上链接」「改价完成」「库存已加」「链接已弹」等操作类播报，对应解决用户「怎么拍」「能不能改价」「没货了」「链接在哪」的诉求，视为针对性回复



\#### ❌ 绝对判定为「非针对性回复」的情形（满足任意一条即不算）

1. 与该问题无关的商品讲解、流程话术（如用户问「什么时候发货」，主播在讲另一款商品的功效，不算）
2. 回应其他用户其他问题的话术（如用户A问「有没有XL码」，主播回复用户B的「能不能退」，不算对A的回复）
3. 模糊不解决问题的套话（如用户问「保质期多久」，主播仅说「大家赶紧拍」「库存不多了」，不算）
4. 仅重复用户问题而不给出答案（如用户问「几号链接」，主播仅说「几号链接？」，不算）
5. 提前预判但未在用户提问后60秒内回应（如主播19:00讲过发货时间，用户19:30再问，19:31之后才再讲，不算）
6. 回复时间超过上述「有效回复时间窗口」的，即使内容相关也不算



\### 三、综合有效回复判定规则

只有**同时满足**「1分钟内回复」和「针对性回复」两个条件，才判定为**综合有效回复**，否则均为无效回复。



\## 特殊情况处理

1. 同一用户连续发送多条相同/相似疑问，以**最早一条**的发送时间计算有效回复窗口
2. 用户弹幕无明确核心诉求的（如仅发「想要」「拍了」「好看」），不纳入统计
3. 主播未开口、无对应话术记录的，直接判定为「无回复」
4. 用户询问已下架/未上架商品的，主播未明确说明的，判定为「无回复」
5. 同一商品的多个规格/库存疑问，主播统一回复该商品整体情况的，视为针对性回复
