# 第三方接口对接文档 — 按行业随机获取直播录制记录

## 基本信息

| 项目 | 说明 |
|---|---|
| 接口路径 | `POST /replay/openapi/thirdparty/randomLiveRecords` |
| 请求方式 | POST |
| Content-Type | application/json |
| 鉴权方式 | 签名验证（HMAC-SHA256） |
| 限流规则 | 每秒10次 / 每分钟60次（按appId维度） |

### 环境地址

| 环境 | 域名 | 完整接口地址 |
|---|---|---|
| 本地 | `http://localhost:6607` | `http://localhost:6607/replay/openapi/thirdparty/randomLiveRecords` |
| 测试 | `https://testapi.aifupan.com.cn` | `https://testapi.aifupan.com.cn/replay/openapi/thirdparty/randomLiveRecords` |
| 生产 | `https://api.aifupan.com.cn` | `https://api.aifupan.com.cn/replay/openapi/thirdparty/randomLiveRecords` |

## 1. 凭证分配

对接前我方会分配以下凭证：

| 参数 | 说明 | 示例 |
|---|---|---|
| appId | 应用标识 | `thirdparty_dev` |
| appSecret | 应用密钥（用于签名，不要在请求中传输） | `Tp8kR2vN7xQ5mW3jL9dY1bF6hA4cE0gU` |

> 以上为测试环境凭证，生产环境凭证将另行分配。

## 2. 请求头（Header）

每次请求必须携带以下请求头：

| Header | 必填 | 说明 |
|---|---|---|
| `X-App-Id` | 是 | 分配的 appId |
| `X-Timestamp` | 是 | 当前时间戳（毫秒），与服务器时间差不能超过15分钟 |
| `X-Nonce` | 是 | 随机字符串（建议UUID），防重放 |
| `X-RequestId` | 是 | 请求唯一ID（建议UUID），同一requestId在2分钟内不可重复使用 |
| `X-Signature` | 是 | 签名值（见下方签名算法） |
| `X-Sign-Type` | 否 | 签名算法，默认 `HMAC-SHA256`，可选 `MD5` |
| `X-Fingerprint` | 否 | 设备指纹（可选） |

## 3. 签名算法

### 3.1 构建待签名字符串

将以下参数按 key 的 ASCII 码升序排列，用 `&` 连接成 `key=value` 格式：

| 参与签名的 key | 对应值 |
|---|---|
| `X-App-Id` | appId 值 |
| `X-Timestamp` | 时间戳值 |
| `X-Nonce` | 随机字符串值 |
| `X-RequestId` | 请求ID值 |
| `X-Fingerprint` | 设备指纹值（如果有） |
| `body` | 请求体 JSON 字符串（如果有） |

排序后示例：
```
X-App-Id=thirdparty_xxx&X-Nonce=abc123&X-RequestId=req-001&X-Timestamp=1712678400000&body={"tradeId":100}
```

### 3.2 HMAC-SHA256 签名（默认）

使用 `appSecret` 作为密钥，对待签名字符串进行 HMAC-SHA256 运算，结果做 Base64 编码。

```java
Mac hmacSha256 = Mac.getInstance("HmacSHA256");
SecretKeySpec secretKey = new SecretKeySpec(appSecret.getBytes("UTF-8"), "HmacSHA256");
hmacSha256.init(secretKey);
byte[] hash = hmacSha256.doFinal(stringToSign.getBytes("UTF-8"));
String signature = Base64.getEncoder().encodeToString(hash);
```

### 3.3 MD5 签名（可选）

将 `appSecret` 拼接在待签名字符串前后，做 MD5 运算，结果转小写十六进制：

```
MD5(appSecret + stringToSign + appSecret)
```

使用 MD5 时需设置请求头 `X-Sign-Type: MD5`。

## 4. 请求参数（Body）

```json
{
  "tradeId": 100
}
```

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| tradeId | Long | 是 | 行业ID |

## 5. 响应结果

### 成功响应

```json
{
  "code": 0,
  "msg": "获取成功",
  "data": [
    {
      "cloudUrl": "https://example.com/live/record/xxx",
      "viewers": 15234,
      "monthlySales": "100万-500万"
    },
    {
      "cloudUrl": "https://example.com/live/record/yyy",
      "viewers": 8920,
      "monthlySales": "50万-100万"
    }
  ]
}
```

| 字段 | 类型 | 说明 |
|---|---|---|
| cloudUrl | String | 云空间链接 |
| viewers | Long | 场观人数 |
| monthlySales | String | 月销售额（区间值） |

每次随机返回 3~5 条记录。查询逻辑：优先匹配指定行业 → 子级行业 → 父级行业 → 全表兜底，保证有数据返回。

### 错误响应

```json
{
  "code": 429,
  "msg": "请求过于频繁，请稍后再试（每秒最多10次）",
  "data": null
}
```

| code | 说明 |
|---|---|
| 0 | 成功 |
| -9 | 参数校验失败（如 tradeId 为空） |
| 401 | 签名验证失败 / 缺少签名参数 |
| 429 | 触发限流 |

## 6. 调用示例（cURL）

```bash
curl -X POST 'https://your-domain/replay/openapi/thirdparty/randomLiveRecords' \
  -H 'Content-Type: application/json' \
  -H 'X-App-Id: thirdparty_xxx' \
  -H 'X-Timestamp: 1712678400000' \
  -H 'X-Nonce: a1b2c3d4-e5f6-7890-abcd-ef1234567890' \
  -H 'X-RequestId: req-20260416-001' \
  -H 'X-Signature: xxxxxxxxxxxxxxxxxxxxxxxx' \
  -d '{"tradeId": 100}'
```

## 7. 注意事项

1. `appSecret` 仅用于签名计算，不要在请求中传输
2. 时间戳与服务器时间差超过15分钟会被拒绝
3. 同一 `X-RequestId` 在2分钟内不可重复使用（防重放）
4. 限流按 appId 维度：每秒10次、每分钟60次
