# aifupan_project 项目简介

本文档记录 `aifupan_project` 仓库内各子项目的职责说明，以及**测试环境**的数据库、中间件与接口访问信息，便于测试、开发与协作时快速定位代码与连接配置。

> **环境说明：** 以下为测试环境信息，来源于项目内配置文件，**仅供查看与联调使用，请勿修改数据库、服务器及中间件中的任何数据或配置。**  
> **配置来源：** 以各子项目 `application-*.yml`、`.env.*`、`public/index.html` 等为准；若与线上实际部署不一致，以运维/部署环境为准。

## 仓库概览

`aifupan_project` 为本项目的全部代码集合，由前端、客户端与管理端后端等多个子工程组成。

## 子项目说明

| 目录名 | 类型 | 说明 |
|--------|------|------|
| `fupan-client` | 前端 | 客户端的前端代码 |
| `ReviewAnalysis` | 客户端 | 客户端代码（桌面端，如 C#） |
| `fupan-server` | 后端 | 管理后台的后端代码 |
| `fupan-governance-server` | 后端 | 企业管理后台的后端代码 |
| `fupan-admin` | 前端 | 管理后台的前端代码 |
| `user_admin` | 前端 | 企业管理后台的前端代码 |

## 结构关系（简要）

```
aifupan_project/
├── fupan-client              # 客户端 - 前端
├── ReviewAnalysis            # 客户端
├── fupan-server              # 管理后台 - 后端
├── fupan-admin               # 管理后台 - 前端
├── fupan-governance-server   # 企业管理后台 - 后端
└── user_admin                # 企业管理后台 - 前端
```

## 端与后台对应关系

|--------|------|------|------------------------------|
