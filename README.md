# 爱复盘（个人备份）

推送到 [xpsxf123/aifupan](https://github.com/xpsxf123/aifupan)。

本仓库包含 `aifupan_project` 下全部子项目：

| 目录 | 说明 |
|------|------|
| `aifupan_project/fupan-client` | 桌面/Web 客户端（Vue） |
| `aifupan_project/ReviewAnalysis` | 桌面端本地录制与分析（C#） |
| `aifupan_project/user_admin` | 企业管理后台（Vue） |
| `aifupan_project/fupan-admin` | 管理端前端 |
| `aifupan_project/fupan-server` | 业务服务端（Java） |
| `aifupan_project/fupan-governance-server` | 治理服务端（Java） |

各目录在公司 Git 上仍是独立仓库；此处仅作个人备份。已排除 `node_modules`、`target`、构建产物、`.env` 和超过 GitHub 限制的大型二进制。
